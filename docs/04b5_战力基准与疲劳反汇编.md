## 1. Q1：战力基准 150
### 1.1 先证伪"150 是算出来的" `[确认]`
`0x442EFA`（B 侧 1438 B）对 `+0x70` 全是 read-modify-write，**无写初值的指令**（`0x442FE8`/`0x44300B`/`0x443029`/`0x443049` 同构；A 侧 `0x443498`：`0x443566`/`0x443586`/`0x4435A9`/`0x4435C7`/`0x4435E7`）：
```
00442FC0  8b4a70   mov ecx,[edx+0x70]     ; edx = unitB = 0x4B03A0
00442FC3  03c8     add ecx,eax
00442FC8  894a70   mov [edx+0x70],ecx
```
### 1.2 初值指令 `[确认]`
全 `.text` 对这两个槽的**绝对寻址只有 4 条**（`dump.txt` §[9]）：
```
0043A3AD  c705 d08a4a00 96000000  mov dword ptr [0x4a8ad0],0x96   ; A 侧 unit+0x70
0043A3B7  c705 10044b00 96000000  mov dword ptr [0x4b0410],0x96   ; B 侧 unit+0x70
00446091  ...                      imul eax,dword ptr [0x4a8ad0]   ; 读: WARINFO05 显示
004462C6  ...                      imul edx,dword ptr [0x4b0410]   ; 读: WARINFO05 显示
```
前两条在 `0x43A1C4`（战斗初始化 796 B）。槽位归属：`0x4A8A60+0x70=0x4A8AD0`、`0x4B03A0+0x70=0x4B0410`，且紧接 `0043A3C1 68608a4a00 push 0x4a8a60 / call 0x43a114`、`0043A3CE 68a0034b00 push 0x4b03a0 / call 0x43a114`；同函数又以这两个基址写 `+0x14/+0x18/+0x1C/+0x20/+0x24/+0x28/+0x2C`（`notes.md` §1.2）。
→ **`unit+0x70` 初值 = `0x96`(150)，无任何运算。**

### 1.3 五段加算全表 `[确认]`（B 侧 `0x442EFA`；A 侧 `0x443498` 完全镜像）
| # | 反汇编 | VA（call / add） | 算式 |
|---|---|---|---|
| 1 兵种相克 | `call 0x430766(己方兵种, 敌方兵种)` | `0x442FB5` / `0x442FC3` | `相克[自][敌]` @`0x48CD88` |
| 2 地形 | `call 0x4307AE(兵种, [0x4A6694])` | `0x442FD5` / `0x442FE3` | `地形[地形][兵种]` @`0x48D030` |
| 3 阵法 | `call 0x4307E5([0x4A8A30],[0x4B4C2C])` | `0x442FF8` / `0x443006` | `阵形[己][敌]` @`0x48D2A0` |
| 4 全局修正 | `mov eax,[0x4A8A4C]; add eax,0x32; cdq; idiv 0x64` | `0x44300E`–`0x44301C` / `0x443024` | `(unit+0x30+50)/100` |
| 5 士气 | `movsx eax,[gB+0x38]; sub eax,0x32; cdq; idiv 5` | `0x44302C`–`0x44303C` / `0x443044` | `(士气−50)/5` |

A 侧：`0x443553/0x443561`、`0x443573/0x443581`、`0x443596/0x4435A4`、`0x4435AC mov eax,[0x4AC364]; add eax,0x32; idiv 0x64`/`0x4435C2`、`0x4435CD movsx eax,[eax+0x38]`+`0x4435DA idiv 5`/`0x4435E2`。
- 第 4 段 `[0x4A8A4C]`/`[0x4AC364]` 由 `0x43A1C4` 从**己方** `unit+0x30` 拷出（`0x43A2E1`/`0x43A2D6`）；`unit+0x30` 写入点 `[未解]`。
- 表索引方向统一"己方在前"：`0x430796 imul edx,edx,0x34`（arg1 做行）+ `0x43079F [edx+eax*4+0x48CD88]`（arg2 做列）。阵形 id：`0x43A102`（side0→`[0x4A6674]`=A）、`0x43A10C`（side1→`[0x4A6678]`=B）；`0x43A1F9 [0x4B4C2C]=[0x4A6674]`、`0x43A205 [0x4A8A30]=[0x4A6678]` ⇒ 两侧都传 `(己方阵, 敌方阵)`。
- 全是**加法**无乘法；`idiv` 为**有符号**除法（负数向 0 截断 → JS 用 `Math.trunc`，不是 `Math.floor`）。
- 加完才进兵力段（`min(带兵,上限)`、`min(骑兵,上限)`、`[unit+0x58]=带兵+骑兵`），与 `+0x70` 无关。

### 1.4 生命周期 `[确认]` 与情报界面 `[确认]`
`0x442EFA`/`0x443498` 唯一调用者 = `0x443A3E`（107 B）← `0x443BE6`（`0x443B84`）← `0x44461E`（`0x444459`）→ **开战前算一次**，判定只读缓存 `unit+0x70`。
`0x445DBF`（`MENU\WARINFO05`）：`0x446081 movsx eax,[g+0x44]`+`0x44608B movsx edx,[g+0x48]` → `0x446091 imul eax,[0x4a8ad0]` ⇒ 显示的"总战力" = `(带兵+骑兵) × unit+0x70`（B 方 `0x4462C6`）。

## 2. Q2：疲劳（`general+0x3A`）
### 2.1 字段身份 `[确认]`（三条独立互证）
1. `0x42D1A3`（TIMES1.INI `[GENERAL]`）不设这三项，只给默认：`0x42D468 mov word [..+0x38],0x50`（士气 80）、`0x42D471 mov word [..+0x3A],0`（**疲劳 0**）、`0x42D47A mov word [..+0x3C],0x5A`（忠诚 90）。
2. `0x42ECCC`（SANGO.INI `[ITEM]`）解析出键 `Tire` → 道具记录 `+0x50`。
3. `0x4088FA`（道具生效）：`0x4089EA` 一带 `mov cx,[g+0x3A] / add cx,[item+0x50] / mov [g+0x3A],cx`，随后 `0x408AD3/0x408AE7` clamp `[0,100]`。
→ `+0x3A` 疲劳（Tire）、`+0x38` 士气（Spirit）、`+0x3C` 忠诚（Loyal）。**`docs/04b` §1.2 的初值写反了，`docs/00` §9 是对的。**

### 2.2 疲劳不进攻力、不进命中 `[确认]`
全 `.text` 45 处 `[reg+0x3A]`（逐函数扫描，`scan_3a_full.txt`）：`0x4078B4`(排序) `0x40856A`(clamp) `0x4088FA`/`0x408BDC`(道具加/减) `0x41048D`(战后) `0x41B1BF`(月末) `0x413C32`/`0x429634`/`0x44EEA6`(UI) `0x42D1A3`/`0x42ECCC`(INI/道具表) `0x4310D0`/`0x431456`/`0x432B5C`/`0x432E92`(存档)。
**`0x442EFA`、`0x443498`、`0x43D400`、`0x43D4CB` 里一处都没有**（另排除跨宽度读：`disp 0x38` 的 dword 读全属别的结构体，general 一律 `word`；`disp 0x39/0x3B` 全段仅 `0x423B9D` 1 字节操作）。

### 2.3 涨点①：战后结算 `0x41048D`（1276 B）`[确认]`
```
00410832  cmp [ebp+0x14],-1      ; 第4参=战斗秒数, -1=未知
00410838  mov eax,[ebp+0x14] / idiv 0xa / 00410841 add eax,0xf  ; 15+秒数/10
00410851  push 8 / call 0x450117 / 0041085E add eax,0xf        ; 15+rand()%8
00410867  mov ecx,[ebp+8] / 0041086A mov edx,[ecx+0x34] / 0041086D and edx,0x1000
004108A8  call 0x4103DE(值, unit+0x38)                         ; 置位时再乘百分比
004108B3  [ebp-0x18]->+0x3A += [ebp-0xC]                       ; A 方
004108C5  [ebp-0x10]->+0x3A += [ebp-4]                         ; B 方
004108DA..004108FB  cmp eax,0x64 / jle / mov word [..+0x3A],0x64 ; cap 100
```
增量 = `15+floor(秒数/10)` 或 `15+rand()%8`（15..22）；**双方都涨**（不是只有败方）；`0x4103DE(v,idx)=v*K/100`，跳表 `0x410471`：K=30/50/75/**100**/150/200/250%，`unit+0x38` 初值 0 → 正常不改结果。同函数回写 `0x4107D6 [g+0x10]=[unit+0x1C]`（体力）、`0x4107EE [g+0x14]=[unit+0x20]`（技力）、`0x4107C3 [g+0x16]=min(..)`。调用者 `0x447424(p1,p2,kind)` 按 kind（1/2/4/8/0x100）定顺序，秒数取 `0x443F2A()`。

### 2.4 涨点②：每月 `0x41B1BF`（1108 B；`0x41B613` 全武将循环 → `0x41B9C3` 周期流程）`[确认]`（"每月"为 `[推测]`）
```
0041B2DA movsx ecx,[g+0x3a] / jle → 跳过
0041B302 mov dx,[g+0x3a] / sub dx,1 / 0041B30D mov [g+0x3a],dx  ; 疲劳>0 则 -1
0041B34E movsx ecx,[g+0x3a] / cmp ecx,0x3c / jl                 ; 疲劳≥60 ?
0041B377 mov dx,[g+0x38] / sub dx,1 / 0041B382 mov [g+0x38],dx  ; 是 → 士气-1
0041B3BD movsx eax,[g+0x38] / cmp eax,0x46 / jge                ; 否且 士气<70
0041B3F1 mov [g+0x38],+1                                        ;   → 士气+1
0041B42B movsx edx,[g+0x38] / cmp edx,0x28 / jge                ; 士气<40 → 忠诚-1
0041B49D movsx ecx,[g+0x3c] / cmp ecx,0x5a / jge                ; 否则 忠诚<90 → +1
```
→ 每月：**疲劳-1**；疲劳≥60 → 士气-1，否则士气<70 → +1；士气<40 → 忠诚-1，否则<90 → +1。

### 2.5 疲劳唯一的战斗影响是间接 `[确认]`+`[未解]`
疲劳≥60 → 每月士气-1 → 战力第 5 段 `(士气-50)/5` 每点 -0.2（整数截断后常为 0）。**疲劳没有任何直接战斗系数。**
`[未解]`：是否影响行军/单挑/技能——`.text` 已无消费点，建议查事件脚本表（EVENT/`MAGIC.SO`）与 `0x44D450` 战前准备。

## 3. Q3：守将属性 → 战斗参数
### 3.1 结论：这层换算不存在 `[确认]`
`0x442EFA`/`0x443498` 从 general 只读 **`+0x38` 士气**，武力/智力一个字节未读。`0x430000`–`0x455000` 内 `word [reg+0x34/0x36]` 160 处命中，真属 general 武力/智力的只有 7 个函数：

| 函数 | 读取 | 用途 |
|---|---|---|
| `0x43D400` | `0x43D431 movsx eax,[g+0x34]` | 兵→将命中 `150−武力*20/100`（`0x43D435 imul 0x14`/`0x43D43E idiv 0x64`/`0x43D440 mov edx,0x96`） |
| `0x43D4CB` | 双方 `+0x34` | 将→将 `150+(STRa−STRb)/2`；将→兵 `150+STR/2`；`0x43B6C9` 目标 `150+STR/3`（`0x43D51C` 后 `idiv 3`） |
| `0x43E72E` | `max(+0x36,+0x34)` | 武将技效果值 ×{130,150,200,76,66,50}%（跳表 `0x43E82B`） |
| `0x44D3E0` | `+0x36` | AI 选目标（智力高优先） |
| `0x441212`/`0x449900`/`0x44EEA6` | 全部 | UI 绘制（`call 0x468A10` 画 `"%-3d"`） |

### 3.2 "兵种强度"来自相克表，不来自武将 `[确认]`
`0x430766` → `相克[己方兵种bit][敌方兵种bit]`（13×13 dword @`0x48CD88`，−68..+68，反对称，对角 0）；bitmask→索引 `0x4491AC`（0..12，无置位返 −1，查不到返 0）。兵种表 `0x4862C8`（13×`0x38`）只有 id/sprite/flag（`+0=100..112`），**没有强度数值** → 所谓"兵种强度" = 相克表加成 + 地形表，与守将属性无关。

### 3.3 技力来自 general 自身 `[确认]`
`0x43A337 [unit+0x20]=(short)g+0x14`、`0x43A355 [unit+0x28]=(short)g+0x16`；战后 `0x4107EE` 回写。`general+0x14/+0x16` 由 INI `BASEMP`（+0x1A）+ 等级成长 + 装备 `MaxMP`（item+0x3E）累积。**不存在 `60+INT/2` 或 INT→技力 的换算。**

### 3.4 建议 `[推测]`
- `bstr/bint` 若是**兵种表数值** → 不能塞进守将 STR/INT（会污染命中率与武将技）；应走 `0x48CD88` 相克表 + 固定兵种基数。
- `bstr/bint` 若只是守将武力/智力的别名 → 现在直接当 STR/INT **是对的**，缺的不是换算层，而是"等级成长+装备"。

## 4. 若要按本文改实现
### 4.1 `game/src/core/battle.ts:372-379` `powerOf()`
```ts
const base = 150 + troopBonus + terrainBonus + formationBonus + moraleTerm(rt.morale);
return Math.round(base * (1 + wiseBonus(world, side, 'troop_atk') / 100));
```
1. `150` **保留**（有证据，勿再标"推断"）。
2. `moraleTerm()` 必须是 `Math.trunc((morale - 50) / 5)`（`0x44302C..0x44303C` 是 `idiv 5`，向 0 截断）；若现在是 `Math.floor`/浮点乘，改这一行。
3. 第 4 项 `(unit+0x30+50)/100` **先不加**：写入点未定位，加恒 0 项等于 +0。
4. 末尾 `(1+wiseBonus/100)` 在 `0x442EFA`/`0x443498` 里**无对应指令**（原作纯加法）；若军师技确有效果，请在别处实现并注释 `[新设计]`。
5. 三项表对齐：`troopBonus=相克[自][敌]`、`terrainBonus=地形[地形][自]`、`formationBonus=阵形[自][敌]`（表值见 `dump.txt` §[7]；行/列是 0..12 的 bit 索引，不是 bitmask）。

### 4.2 `battle.ts:389-403` `hitChance()`
- 兵→将 `150 - Math.trunc(str*20/100)`（`0x43D431/0x43D43E/0x43D445`）；将→兵 `150 + Math.trunc(str/2)`（`sar 1`）；将→将 `150 + Math.trunc((strA-strB)/2)`（`sub/cdq/sub/sar 1`）。
- **补漏分支**：目标满足 `0x43B6C9`（`target->+0x2C & 4`）→ `150 + Math.trunc(str/3)`（`0x43D51C` 后 `idiv 3`）。
- 未就位惩罚：`0x43BE08(def)==0`（`def->+0x08 != +0x10 || def->+0x0C != +0x14`）→ `p = Math.trunc(p*2/3)`（`0x43D45A..0x43D465`）。

### 4.3 疲劳（若要在重制版里实现）
- 战后：`fatigue = min(100, fatigue + 15 + Math.trunc(seconds/10))`，秒数未知用 `15 + rand()%8`；**双方都加**（`0x41048D`）。
- 每月：`fatigue = max(0, fatigue - 1)`；`fatigue>=60` → `morale -= 1`，否则 `morale<70` → `morale += 1`（`0x41B1BF`）。
- **不要**接进 `powerOf()` 或 `hitChance()`——原作没有。

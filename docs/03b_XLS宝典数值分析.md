# 《三国群英传2》数值体系分析（XLS 宝典 + MAGIC.INI）

> **一句话结论**：这是一套"双轴（武力/智力）+ 相克（兵种 13×13、阵形 9×9）+ 门槛（技能按等级解锁）"的乘法式数值体系——武力均值 66.6、智力均值 64.3 但中位数 70/66，说明它刻意做成"少数名将拉高上限、大量庸将构成底座"的长尾结构；兵种单格相克极值 +68 点（非对角平均 |37.36|）、阵形 +25 点，量级上足以覆盖 20–30 点武力差；而两张相克表都是**严格反对称的零和表**，不是单向优势。

**证据来源**（全部实算，无估算）：

**编码提示**：`MAGIC.INI` 实际编码是 **cp950(Big5)**，不是 GBK；用 GBK 解码会在第一个中文字节处报错（例：`NAME` 原始字节 `A9 52 C0 F8 B3 4E` → cp950 得「命療術」）。本脚本按 cp950 解码后再用 `LCMapStringW(0x02000000)` 转简体，并补丁 `後→后`、`鍾→钟`（系统 API 漏转/误转，`郃→合` 属误转，但技能/城池名不涉及）。

## 2 武将技 110 条

### 2.1 总览

| 字段 | 均值 | 中位数 | 最小 | 最大 |
|---|---|---|---|---|
| 消耗技力 MP | 33.84 | 35.0 | 18 | 50 |
| 能量（气）POWER | 100.0 | 100.0 | 100 | 100 |
| 攻击力 ATTACK | 10.52 | 8.0 | 0 | 60 |
| 调用代码 SCRIPT | 555.5 | 555.5 | 501 | 610 |

三个关键事实：

1. **`能量（气）` 110 条全部 = 100**，是常量而不是变量——它只是"气力槽上限 =100%"的占位，不参与平衡。
2. **`调用代码` 是 501–610 的一个排列**（110 个值互不重复，恰好覆盖 501–610），即"一个技能一个独立脚本函数、无复用"；但**编号与序号并不同序**，110 条里只有 16 条满足 `SCRIPT = 500 + 序号`（如序号 3 的脚本是 504、序号 4 是 503）。说明脚本表是按功能/历史顺序排的，**不能拿序号去猜脚本地址**。
3. **攻击力 0 的有 25 条（22.7%）**——这 25 条是纯功能技（补血/补兵/增益），伤害为 0 但效果由脚本实现，所以"攻击力"字段只描述直接伤害部分。

### 2.8 与 MAGIC.INI [MAGIC] 的名称/字段 join

## 7 数值设计观察与给新游戏的建议

### 7.1 这套体系的平衡特征

**(1) 双轴基本独立，但稀缺度刻意不对称。** 武力 × 智力 r = **-0.39**（r² = 0.15，只解释 15% 的方差）——方向上是"武力越高、智力略低"，属于弱负相关，远没到互斥。真正的不对称在**供给量**：武力 ≥90 有 30 人、智力 ≥90 有 42 人；武力中位 70、均值 66.6。设计含义：**猛将比谋士更难获得**，玩家的核心追求自然落在武将而非军师。

**(2) 强度靠"槽位数"分层，不靠"单技能数值"。** 必杀技 7 槽从 400 人递减到 88 人，军师技 8 槽从 400 递减到 31 人；而单技能的攻击力只有 0–60、技力 18–50，压缩在一个很窄的带里。**名将的差别是"技能数量 × 解锁速度"，不是"同样的技能打得更疼"**——这让低级将也有存在感。

**(3) 解锁曲线是"加速型"，不是常见的"减速型"。** 7 个必杀技槽的平均解锁等级为 1.0 / 8.8 / 16.3 / 22.3 / 27.4 / 31.5 / 35.4；相邻槽的间隔是 7.8 / 7.4 / 6.1 / 5.1 / 4.0 / 3.9——**越到后期间隔越短**（7.8 级 → 3.9 级）。这是刻意的后期补偿：高级玩家升级更慢，就用"更密的技能投放"维持正反馈，而不是把强力技能堆在 1–10 级制造开局爽感。

**(4) 相克幅度足以覆盖一个档次的数值差。** 兵种单格极值 **+68**（大刀 打 藤甲）、非对角平均 |37.36|；阵形单格极值 +25。相克点数的单位未公开，但**若与武力同量纲**，单格 68 点已接近整个武力区间（30–100，宽 70 点）——**一次正确的兵种选择能抵掉 20–30 点武力差**，足够让"以弱胜强"成立。这是把"策略"抬到与"数值"同等权重的关键设计。

**(5) 装备是"第二成长线"，不是补丁。** 武器把武力加成做成与使用等级绑定的阶梯（+1 → +30，跨 1–45 级），书籍给智力（+7 → +20），坐骑给速度（+1 → +6）；体力/技力/士气/疲劳四列全空——**本作根本没做这些轴**。真正改变战局的是 13 张兵符 + 9 本阵书（扩"可选集合"）。

**(6) 地图是"资源分布"而非"背景"。** 12 座关（等级 0）人口 = 金钱 = 0、防御恒 100（全表最低）——它不是要塞，而是"拖慢行军的一次性减速带"；48 座城承载税基（人口 58500–411500，金钱/人口 ≈ 0.020）。路网 77 条可通行边、平均度 2.57、直径 2084，**没有超级枢纽**——战略价值来自"位置"而非"度数"（定陶、壶关这类关的度数为 3–4，恰说明它们是"通过型节点"：谁占谁收过路费，但收不到税）。

### 7.2 给新游戏的 10 条可执行建议

| # | 建议 | 具体数值区间（可直接照搬 / 微调） |

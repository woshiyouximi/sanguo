### 2.2 成功率判定 `0x404344`（486 B）[确认]

签名：`int f(King* 招降方 /*[ebp+8]*/, general* g /*[ebp+0xc]*/)`，返回 1=成功、0=失败；全局 `0x4C6CEC` 存结果码。

```c
[0x4C6CEC] = 1;                                     // 0x40434C
L = (short)g->+0x3C;                                // ★ 忠诚度
if (L < 0x19) return 1;                             // 忠诚 < 25 → 必成功（不掷骰）
C = (short)g->+0xC7;                                // 节操 CONSTANCY
t = (C >= 5) ? 1 : (C >= 3) ? 0 : -1;               // 节操档位
if (g->+0xBF != 0) {                                // ★ +0xBF = INI 的 LOYAL（情义势力）
    King* k0   = g->+0xBF;
    general* kd = k0->+0x0C;                        // 该势力君主
    if (k0 == 招降方) { [0x4C6CEC] = 6; return 1; }              // 0x4043CC 已属我方
    if (kd->+0xCB == k0) t += 2;                                 // 原势力健在 → 难度 +2 档
    else if (kd->+0xCB == 招降方 && kd->+0x91 == 1) {            // 0x404413 旧主已降
        [0x4C6CEC] = 2; return 1;                                //   → 必成功
    }
}
if (t < 0) {                                        // 节操 < 3
    [0x4C6CEC] = 3;                                 // 0x40442D
    if (rand()%100 >= L) return 1;
    if (rand()%100 >= L) return 1;                  // 两次机会
} else if (t == 0) {                                // 节操 3~4
    [0x4C6CEC] = 1;                                 // 0x40447D
    if (rand()%100 >= L) return 1;
} else {                                            // 节操 >= 5
    if (rand()%100 >= L && rand()%3 == 0) return 1; // 先过后 1/3
}
if (t >= 2)      { [0x4C6CEC] = 0x10; return 0; }    // 0x4044D8 ★ 宁死不降（覆盖上面的成功）
if (L > 0x5A)    { [0x4C6CEC] = 0x11; return 0; }    // 0x4044F0 忠诚 > 90
if (L > 0x46)    { [0x4C6CEC] = 0x12; return 0; }    // 0x404508 忠诚 > 70
if (L > 0x32)    { [0x4C6CEC] = 0x13; return 0; }    // 0x404520 忠诚 > 50
return 0;
```

**等价的概率式**（`L`=忠诚度 0~99，`C`=节操）：

| 条件 | 成功率 |
|---|---|
| `L < 25` | 100%（先于一切判定） |
| `C < 3` 且原势力已亡（`t=-1`） | `1 − (L/100)²` |
| `C = 3~4` 且原势力已亡（`t=0`） | `1 − L/100` |
| `C ≥ 5` 且原势力已亡（`t=1`） | `(1 − L/100) / 3` |
| `C = 3~4` 且原势力健在（`t=2`） | **0（宁死不降）** |
| `C ≥ 5` 且原势力健在（`t=3`） | **0（宁死不降）** |
| 其 LOYAL 势力就是招降方（`k0==招降方`） | 100%（code 6，防御性分支） |
| 其原主君已归顺我方且原势力 `STATUS==1` | 100%（code 2） |

要点：
1. **决定难度的是"节操 + 原势力是否存在"，不是疲劳度**。此前若把 `+0x3C` 当疲劳度，公式会被读成"疲劳越低越易招"，实际是"**忠诚越低越易招**"（§6.1 有面板串证据）。
2. **"宁死不降"是 `t += 2` 这一支**：`g->+0xBF`（INI `LOYAL` 势力）存在且该势力的君主仍是自己的主君（`kd->+0xCB == k0`），则 `t` 加 2；只要节操 ≥3，`t ≥ 2`，函数在掷骰后无条件返回 0。
3. `L < 25` 的早退**优先于**宁死不降 —— 忠诚已经崩到 25 以下的节操高将也能被招走。这解释了 §4.1 里"被俘者忠诚 −(10−节操)×2"为什么是招降的关键前置。

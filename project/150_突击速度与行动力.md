# 150 突击速度与行动力（`RUSH_SPEED` / `0x4000`→46 / `0x120` 的 11 个值）

> **三条结论**：① 全 EXE **没有突击速度倍率**——`AllRush` 在 EXE 侧只做「暂停整场战斗 + 给单位挂一个演出锁」，`RUSH_SPEED` 真值 = **1.0**；② `0x4000` 是**撤退/溃退**态，46 帧写在 `unit+0x34`（与常规 40 **同一字段**），加在**军团+全部小队**、不是主将专属；③ 那 11 个值不是命令位，是 `0x120` 的**动画动作号**，EXE 只当「有演出待执行」的非零标记，**不按值分派**。
> 三份逐字节证据：`work\re_speed\rush_speed.txt` / `state4000.txt` / `cmd_bits.txt`。

## 1 突击速度倍率：不存在，`RUSH_SPEED` = 1.0 `[确认]`

**结论**：原作突击**不改步长、不改行动间隔**；`SYSTEM.SO#22 AllRush` 的全部 EXE 副作用只有下面 4 件，没有第 5 件。

| # | 地址 | 做了什么 |
|---|---|---|
| ① | `0x4442FE` 置 `[0x4A6660]=1` / `0x44430D` 清 0 | **全局突击标志**。战斗主 tick `0x402EA5` 在 `0x402EAB cmp [0x4a6660],1` 后 `jmp 0x403D0F`，而 `0x403D0F` 是**函数尾声 `mov esp,ebp; pop ebp; ret`** ⇒ 突击期间**整个战斗 tick 直接返回**，谁都不动 |
| ② | `0x43AB7F` 冻结 / `0x43AC79` 解冻 | 对双方军团（`0x4A8A60` / `0x4B03A0`）及其 `i<[army+0x58]` 个小队：活着则 `x->+0x3C = 0x270F`(9999)；解冻时 `x->+0x34 += (now-起点)`、`+0x3C = 0` ⇒ 只把演出耗时**补回**冷却，不是加速 |
| ③ | `0x4206CE`（`0x120` handler） | `0x120(unitId, 0x10000)` → `animobj+0x6C = 0x10000`，一个演出锁（见 §3） |
| ④ | 脚本侧 | 镜头 `MoveCamera`、音效 `Rush01`、文本 `全軍突擊!%k%%e%`，非 gameplay |

- 唯一的行动间隔函数 `0x43B574`（士兵 `0x43D24B` 与主将 `0x43EB50` 共用）**通篇没有任何 `[0x4A6660]` / 突击分支**：`[u+0x34] -= 1; if >0 return 0;` 再复位 40 / 46 / `46+2Δ`。
- 全 .text 的 `0x10000` 立即数 110 处已逐点排除：只剩 `0x4421A2`（对象 flag）、`0x442653`（`[0x4A6760]` 输入/渲染 flag）和一堆定点数 1.0（`0x457E87`/`0x458631`/`0x456E3A`…），**无一与移动/步长/速度有关**。
- ⇒ EXE 里没有「突击倍率」这个数。本作用 **1.0**（=普通推进）最接近原作：把「压上去」的观感交给**目标点差异**（突击=朝最近敌前压、到 `ENGAGE_RANGE` 停），不乘系数。

## 2 `0x4000` → 46 帧：是撤退态的行动间隔，同一字段 `+0x34` `[确认]`

**结论**：`0x4000` = **撤退/溃退态**（与兵种、阵形、主将身份都无关），46 是**行动间隔**、写 `[unit+0x34]`；旧记录「`+0x2e` = 46」是 `work\dis_battle_units.txt:1633` 的列错位误读。

- **谁置位**（`SetState 0x43B51E` 的 13 个 caller 里 mask=`0x4000` 的 4 个）：
  - `0x4447B7(army)` 全军撤退：`0x4447C6 push 8 / push 0x100 / call 0x43ADED`(全军命令槽=8) → `0x4447D9 push 0x4000` + `0x4447E2 call 0x43b51e` 置**军团自身**；`0x444825`–`0x444858` 循环 `i<[army+0x58]`、`lea edx,[ecx+eax+0xb4]`(eax=i*0x48) 逐个小队 `|= 0x4000`；`0x4447ED`–`0x44481D`：`[army+0x84]&0x40` 非 0 → 发 `0x1000B` 消息并 `0x444814 push 0x8000` / `0x44481D call 0x43b51e` 再置 `0x8000`（`docs\04b3:430` 记该分支=主将阵亡）。
  - `0x43C7E3` / `0x43CC95`（溃退）：`cmp [unit+0x40],0x4A8A60` 判敌我 → `call 0x43C4C0(unit,±1,0,cfg)` → 无条件置 `0x4000`（`0x43C81E` / `0x43CCD0`）。
- **谁消费**（对 `GetState 0x43B50D` 返回值做 and 的 6 处）：`0x43B5F1`（间隔→46）、`0x43B694`、`0x43BCD8`、`0x43BD74`、`0x43C684`（已在该态则改走 `0x43AF54(x,0)`）、`0x43D8E4`。
- **46 的字节**：`0x43B5DE c7 41 34 28 00 00 00`（`[u+0x34]=0x28`）→ `0x43B5FD c7 40 34 2e 00 00 00`（`[u+0x34]=0x2E`）。**同一 `+0x34`**。第三档 `0x43B64A 8b 48 34` / `0x43B64D 8d 14 51 lea edx,[ecx+edx*2]` / `0x43B653 89 50 34` = `46 + 2*(C-B)`（当 `0x43B6A8` 测出 `state&1`），B/C 是两次 `0x4429FD` 取的 `movsx word [x+0x40]` 坐标差。
- 与**兵种**无关（`0x43B574` 不读 `[u+0x54]` 兵种数组）、与**阵形**无关；与**军师技**关系 `[未解]`（`0x43B574` 全 0xEF 字节与 6 个消费端都不引用魔法/AI 表）。

## 3 `0x120` 的 11 个值：动画动作号，不是命令位 `[确认]`

**结论**：`unit+0x6C` = 命令字这个模型在 EXE 里**不存在**。`0x120` 写的是**精灵对象**的 `animobj+0x6C`（待执行动作号），全 EXE 只有 `0x421DF7` 读它、且只判「是否非零」。

- `0x4206CE`（opcode 0x120）：`arg1` 经 `0x421A80` 解析成对象（池 `[0x4A64A0]`、stride `0xA8`、`+4` 存 id 校验、id>0x800 拒绝）→ `[obj+0x34]==0x20`(DEATH) 则丢弃 → `mov [edx+0x6c],0` → `call 0x421E1B(obj,arg2)` → 只拒 `-1` → `mov [edx+0x6c],arg2`。
- `0x421DF1(obj,act)`：`cmp [eax+0x6c],0` 非零时，只有 `act==0x20`(死亡)/`0x40`(倒地) 放行、其余拒绝 ⇒ 语义 = **演出锁**（法术收尾 `WAIT 15/20` 后补一发 `0x120(u,0x8000)` 就是锁住这员将）。
- `0x421E1B` 只认 `1/2/4/8/0x10/0x20/0x40/0x80/0x100/0x200/0x400`（按 `[[obj+0x7C]+4]`=1/2/3 查三张 `[t+0x28]` 指针表），**≥0x1000 一律落 default 返回 0**（不是 -1，所以照样被存）⇒ 大值在 EXE 里等于「空动作占位」。

| `0x2` / `0x4` | 2 / 2 | #138 TraceDuplicator、#338 XTraceDuplicator | 残影/分身（两段） | `[推测]` |

## 4 对代码的具体建议

1. **`RUSH_SPEED` 改 1.0**（`game\src\core\battle.ts:1868`，并改 `:1857-1867` 注释）：原作无倍率，「突击更快」是观感差异不是系数。
2. **`actionIntervalOf` 保持三值，但把注释改对**（`:82-90`）：46 与 40 是**同一字段** `unit+0x34`，不是 `+0x2e` 独立字段；`0x4000` 也不是主将专属（军团+小队都置），只是本作只给主将用这条闸。
3. **改三处过时注释**：`:370-371`、`:1859-1863`、`:1899-1900` 仍写「`0x10000` 是突击命令位、写进 `unit+0x6c`」——应改成「`0x120` 写精灵对象 `animobj+0x6C` 的演出动作号」。

```diff
-export const RUSH_SPEED = 1.3;
+export const RUSH_SPEED = 1.0;   // [确认] 原作突击无速度倍率（AllRush 只暂停战斗 + 挂演出锁）
-export const GENERAL_SLOW_INTERVAL = 46;  // 注释：与 40 不是同一字段（+0x2e vs +0x34）

```

## 1. 统一开关：`game/web/devflags.js`

原来每个调试口各自 `new URLSearchParams(location.search)`，谁都能从地址栏触发。现在收成一个文件：

```js
var Q = new URLSearchParams(search);
var DEV = /[?&]dev=1/.test(search);   // devflags.js:27
```

对外只挂 `window.SGDev`（**classic script，不是 ESM** —— `index.html` 的 solo 内联脚本和 `items.html` 的模块都要用，而 `main.js` 是 module，classic 三种都能读）：

| API | 含义 |
| --- | --- |
| `SGDev.DEV` | 是否带 `?dev=1` |
| `SGDev.val(name)` | 原值；**非 DEV 一律 `null`**（`devflags.js:31`） |
| `SGDev.on(name)` | DEV 且值 ∈ `''/1/true/yes/on` → `true`（`devflags.js:36`） |
| `SGDev.num(name, def)` | DEV 且能解析成有限数 → 该数，否则 `def` |
| `SGDev.query` | 底层 `URLSearchParams`（给需要原样转发的场景） |

**设计取舍：缺省是「关」不是「开」。** 三个消费方都写了「拿不到 `window.SGDev` 就退化成全关」的 shim：

- `main.js:31` `const SGDEV = window.SGDev || { DEV: false, val: () => null, on: () => false, num: (_k, d) => d };`
- `items.html:363` `const devQ = window.SGDev || { DEV: false, val: () => null };`
- `index.html:344` `var devOn = !!(window.SGDev && window.SGDev.DEV);`

所以 `devflags.js` 404、被 CSP 挡、被裁剪，或者有人手删这一行 `<script>`，结果都是**调试口全关**，而不是裸奔。这条不变量由 `release_check.mjs` 的 **C4**（`[?&]dev=1` 只许出现在 `devflags.js`）守着。

## 5. 首屏与兜底

### 5.1 `index.html` 首屏守卫（`index.html:318-410`）

玩家能看到的永远是四段人话之一（标题 / 发生了什么 / 下一步），一次「重試」按钮，**技术细节默认隐藏**：

| kind | 标题 | 人话 |
| --- | --- | --- |
| `script` | 遊戲檔案沒有載入完整 | 這次只載入到一部分檔案，可能是更新到一半或快取出錯。按「重試」重新載入一次通常就好了。 |
| `canvas` | 這台裝置畫不出遊戲畫面 | 瀏覽器沒能建立遊戲用的畫布（Canvas 2D）。請換 Edge / Chrome 最新版再開；手機上先關掉省電模式。 |
| `crashed` | 遊戲啟動時出錯了 | 遊戲在啟動過程中遇到問題，暫時停住了。按「重試」再開一次；一直這樣就換個瀏覽器試試。 |
| `timeout` | 遊戲載入太久，先停下來了 | 資料還沒讀完，或畫面沒能開始執行。確認網路後按「重試」；離線版請確認檔案是完整的。 |

判定来源（`index.html:329-410`）：

1. `<script>` 载入失败（含 `main.js` 里 `../dist/**` 的静态 import 404 —— 浏览器把这类失败报在 script 元素上）：捕获期 `error`，`ev.target.tagName === 'SCRIPT'` → `show('script', 'script 載入失敗：'+src)`（`:370-376`）；
2. Canvas2D 建不出来：`cv.getContext('2d')` 为 null 或抛错 → `show('canvas', …)`（`:385-388`）；
3. 启动期未捕获异常 / 未处理的 Promise 拒绝 → `show('crashed', msg + '\n' + file + ':' + line)`（`:374-382`）；
4. 看门狗：15s 还没 `window.__sanguo.booted` → `show('timeout', …)`（`:393-399`）。

**`booted` 之后不再全屏拦人**（`:374`、`:378` 的 `if (booted || shown) return;`）—— 开打之后来个偶发异常，不该把战场糊住；那些交给 `main.js` 的诊断面板和 `__sgBootFail`。

技术细节 `:360-363`：`pre.textContent = tech`，且 **`det.hidden = !devOn; det.open = devOn`** —— 只有 `?dev=1` 才看得见（对比截图 `05` vs `03`）。原来的 `#error` 里那套「請在 `F:\sanguo\game` 目錄執行 `node web/serve.mjs`、打開 `http://127.0.0.1:5173/web/`、不要雙擊 index.html」**已整段删除**（那些话对玩家没意义，而且是发布包里不该出现的本机路径/端口）。

### 5.2 `main.js` 诊断面板 + 全局钩子（`main.js:1455-1525`、`1680-1700`）

- `diagPush(where, err)`：Error → 第 1 行摘要 + stack 前 6 行；最多留 `DIAG_MAX = 12` 条（超了 shift 掉最旧的）。
- `diagRender()`：首次创建 `<details id="sg-diag">`，固定在左下角（`z-index:60`、宽 ≤560px、高 ≤45vh、等宽 11px），`summary` = `🛠 診斷 N 條`，**`diagEl.open = SGDEV.DEV`（`:1501`）** —— 发布态是收起的，玩家看不见；`?dev=1` 时自动展开。

## 10. 遗留与风险

1. **`campaign`/`city` 的 30+ 个调试口仍然裸露**（§8）。这是本次最大的剩余面，需要 lead 派工；统一收口的最小改动是「非 `?dev=1` 时把 `qs` 换成空对象」。
2. **`audio.js` 的 `?terrain=` 能被绕过**：即使 `main.js` 收紧了，BGM 仍会跟着 URL 变。
3. **15s 看门狗是静态阈值**：非常慢的机器/网络下会误报「載入太久」。如果将来首屏资源（当时 8.1s）继续变大，这个阈值要跟着调，或者改成「有进度就续命」。
4. **`03-fallback.png` 的技术细节只显示 `script 載入失敗：./main.js`**：模块依赖 404 时浏览器只把失败报在入口 script 上，具体是哪个 `../dist/*.js` 得靠 DevTools 或 `?dev=1` 下的诊断面板（`main.js` 能加载时才有）。
5. `release_check.mjs` 的 C6 只做**可达性**（文件在不在），不校验导出的符号名是否还在 —— 那需要真跑浏览器，超出静态自检的范围。

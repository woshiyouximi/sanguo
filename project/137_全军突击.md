## 1. 原作证据链（照这个实现，没有自己发明）

### 1.1 `AllRush` 的全 22 条指令

`extract/pak/SCRIPT/SYSTEM.SO` 函数 #22：`name=AllRush`、`num=0x3B`、`off=0x2B0C`、`argc=0`。
反汇编 `export/script/system_so.dis.txt:1536-1585`，逐条：

| # | 指令 | 落点 |
|---:|---|---|
| 1 | `PUSHN 3` | 局部槽 3 个 |
| 2 | `SYSCALL 0x131` | `screenFlash(true)`（特效压暗） |
| 3 | `SYSCALL 0x122` | 未实现 no-op（占位 trace） |
| 4 | `PUSHS "MoveCamera"; WAITFOR` | 等镜头移动完 |
| 5-6 | `LDG 2; SYSCALL 0x105` → loc1 | 主将像素 x |
| 7-8 | `LDG 2; SYSCALL 0x106` → loc2 | 主将像素 y |
| 9 | **`LDG 2; PUSHI 65536; SYSCALL 0x120, 0x2`** | **全体部队命令字 = 0x10000（突击）** |
| 10 | `LDSL loc1; LDSL loc2; PUSHI 128; SUB; PUSHI 20; CALL MoveCamera` | 镜头推到自己主将（y−128，20 帧） |
| 11 | `SYSCALL 0x123` | 未实现 no-op |
| 12-15 | `PUSHI 155; LDG 5; SYSCALL 0x10C; PUSHI 2; DIV; ADD` → loc3 | 音量 = 155 + 阵营号/2 ⇒ 155 或 156；`>255` 夹取永不触发 |
| 16-17 | `PUSHS "Rush01"; LDSL loc3; SYSCALL 0x301, 0x2` | 播突击音 |
| 18-20 | `PUSHI 3; LDG 5; SUB; PUSHI 0; PUSHS "全軍突擊!%k%%e%"; SYSCALL 0x3, 0x3` | 弹台词 |
| 21 | `PUSHI 44; WAIT` | 停 44 帧 |
| 22 | `SYSCALL 0x110` → `RET 0` | 恢复亮度 |

结论：原作这条命令 = **「闪白 + 镜头 + 播报 + 全体命令位切突击」**，玩法上只把部队从「原地/待机」
切到「突击」，由各单位自己朝敌方推进。它**没有**目标选择、**没有**伤害或攻击力加成（见 §5 第 17 条测试）。

### 1.2 `0x120` 的宿主实现

`export/script/syscall_handlers.asm.txt:1397-1426`：

```
obj = 0x421a80(arg1)        ; 句柄 → 对象
if (!obj) ret
if (obj[0x34] == 0x20) ret  ; 类型过滤
obj[0x6c] = 0               ; 先清 0
if (0x421e1b(obj, arg2) == -1) ret
obj[0x6c] = arg2            ; 再写命令字
```

即 `0x120` = **「把命令字写进 unit+0x6c」**，`0x10000` 是其中的「突击」位。

## 6. `0x120` 观察到的命令位（MAGIC.SO 全量实参扫描）

## 7. `[推测]` 清单（原作没有直接证据的部分，全部标明）

### 7.1 `[推测]` 推进速度倍率 `RUSH_SPEED = 1.3`

- 已定位的：`0x120` 只写命令字（§1.2），**没有**速度参数；`AllRush` 的 22 条指令里也没有速度常量。
- 因此「突击比普通推进快多少」在字节码里**不可见**，只能从手感取一个数：取 `1.3`
  （普通 1.0 < 突击 1.3 < 撤退 1.5，即 `RETREAT_SPEED` 那一套常量风格）。
- 影响面：只有推进速度；测试 #6/#7 把当前值钉成 0.117 格/tick 与 ×1.30，将来若从原作挖到真值，
  改 `battle.ts:1841` 一处即可，测试会立刻指出差异。

### 7.2 `[推测]` / **未做**：突击态**不**抑制自动撤退

- 你给的验收口径是「突击态下该侧 `maybeRetreat` 不触发；**若判断没有依据就不要加**」。
- 判断：**没有依据**。`AllRush` 字节码里没有「关掉 AI 撤退」的调用；`0x120` 只写命令字；
  原作 `0x4447B7`（「全军转 cmd 8」）是撤退自己的命令改写，跟突击无关。
- 所以**本轮没有**加这条抑制，`maybeRetreat()` 保持原样（`battle.ts:1823` 起）。
  `requestRetreat()` 在突击态下**仍然生效**（测试 #8 正向钉住），并且撤退成功会把 `rush` 清回 false
  （`battle.ts:1865`）—— 这一条是**为了 HUD 不自相矛盾**（一边「突擊中」一边往外走）而加的，
  属于实现口径，不是原作证据。

### 7.3 `[推测]` `0x120` 的位语义

- 实证的只有 `0x10000 = 突击`（`AllRush` 的唯一调用点 + 视觉/音效表现对得上）。
- 其余 10 个位值（§6）**只知道出现过、不知道该位在 `unit+0x6c` 里代表什么**（原作是位域/枚举混合，
  `0x421e1b` 的校验逻辑没有逆完）。本作对它们一律 no-op + trace，不猜。

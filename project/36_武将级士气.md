# 36 · 武將級士氣

> 狀態：已落地。原作《三國群英傳 2》的 `general+0x38` 士氣（0..100），本作從「城池級近似」
> 改成「武將級真實值」，並把 `疲勞 → 士氣 → 戰力第 5 段` 接成閉環。
> 反彙編見 `docs/04b5_战力基准与疲劳反汇编.md` §Q2、`docs/04b_战斗系统.md` §2.5/§6.5。

## 1. 原作依據

- 欄位：`general+0x38` = 士氣（`word`，0..100）；`+0x3A` = 疲勞；`+0x3C` = 忠誠。
- 初始：`0x42D468 mov word [..+0x38],0x50` = **80**；`0x42D471` 疲勞 0；`0x42D47A` 忠誠 90。
- 戰力第 5 段：`0x44302C..0x44303C`（B 側）/ `0x4435CD`（A 側）
  `movsx eax,[g+0x38]; sub eax,0x32; cdq; idiv 5` → `trunc((士氣−50)/5)`，向零截斷。
  五段是純加法：`150 + 相剋 + 地形 + 陣形 + (unit+0x30+50)/100 + 士氣項`（`0x43A3AD` 的 `0x96`）。
- 士氣另有獨立懲罰函數 `0x43A14D`（不經戰力）：`m>50 → −1；v=clamp(m,4,50); return v*6`，
  推測是士兵行動/出手節奏；本作未接（只接戰力第 5 段）。
- 每月 `0x41B1BF`：疲勞 >0 先 −1（下限 0）；再用減後值判 `>= 0x3C(60)` → 士氣 −1（`0x41B377`）；
  否則士氣 < `0x46(70)` → 士氣 +1；之後才是忠誠加減。
- 戰後 `0x447520`：對 `status=3`（被俘/敗）的武將 `+0x38 -= 0x14` = **−20**、忠誠 `-= (10−CONSTANCY)*2`。
  原作**沒有**「戰敗主將一律 −10」這條。

## 2. 資料結構

```json
{ "owned": ["代縣"], "cities": { "代縣": { "troops": 1200, "pop": 80000, "money": 300,
    "cityMorale": 70 } },
  "tire":  { "關羽": 63, "張角": 15 },
  "morale": { "關羽": 55, "張角": 60 } }
```

- `morale` 只存在戰役存檔（槽 snapshot / 舊鍵 `sanguo_campaign_v1`），**沒有改 `saves.js` 的槽結構**，
  也沒有預先塞滿名冊：讀取時 `moraleOf(save, name)` 對缺的名字回缺省 60。
- 值一律夾成 0..100 整數；壞值（`null`/布林/`''`/非數字）在 `moraleNormalize()` 丟掉。
- 與 `tire` 完全分開：士氣邏輯不寫 `tire`，疲勞邏輯不寫 `morale`（測試有互不污染斷言）。

## 3. 遷移規則（老檔）

1. `morale` 缺欄位 → `moraleNormalize(undefined)` = `{}`；所有武將按 **60** 讀（不是原作的 80，
   避免老檔一讀檔就全體變強；新將仍是 60，原作 80 留待統一調平衡時再議）。
2. 舊近似把士氣寫在城池上（`cities[城].morale`）。`moraleMigrateCities()` 把它**改名 `cityMorale`**
   保留數值，**不搬成武將士氣**（同名會打架，武將級才是真的）；重複遷移是無操作。
3. 遷移只改名、不刪城、不動 `tire`/`owned`/`gold`；`campaign.html` 啟動時提示
   「N 座城的城池級 morale 已改名 cityMorale」。直接丟掉城池級數值也是選項，這裡選保留以免損失資訊。

## 5. 與驗收數字的差異（重要）

- 任務驗收寫「士氣 20/60/100 → 戰力 −6/0/+10」，那是 `(士氣−50)/5`（`MORALE_DAMP=1`）的結果。
- 實際 `game/src/core/battle.ts:48` 的 `MORALE_DAMP = 2`，`moraleTerm()` 等於 `trunc((士氣−50)/10)`：
  20/60/100 → **−3/+1/+5**（相對士氣 50）。本輪硬邊界禁止改 `game/src/core/**`，所以測試斷言實際值、
  差異記在這裡；要回到 −6/0/+10 只需把 `MORALE_DAMP` 調回 1（測試第 8 條會指出要同步哪三行）。

## 6. `[新設計]` 標註

1. **士氣 <30 每月自然 +1**：原作是「疲勞 <60 且士氣 <70 → +1」，門檻 70；本作改 30 以形成閉環。
2. **戰敗主將 −10**：原作只有被俘（status=3）−20，沒有「戰敗 −10」；−10 是本作簡化。
3. **新將/老檔缺省 60**：原作新將 80；沿用 60 是為了不動既有平衡。
4. （未接）原作 `0x43A14D` 的士氣→出手節奏懲罰；本作士氣只進戰力第 5 段。

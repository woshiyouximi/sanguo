## 1. 真兇：`markCityTaken()` 不分 defend

R245 之後的結算順序（`game/cocos/assets/scripts/BattleRoot.ts` → `GameState.recordBattleResult`）：

```
recordBattleResult('樂陵', 'A', 'B1', defend=true)
  won → owned.push(city) → markCityTaken(save, city)
        ├─ takenOver[樂陵] = month      ← 這座城從此不再回落劇本表
        ├─ cities[樂陵].officers = []   ← 守將快照清空
        └─ delete roster[樂陵]           ← 整城名冊刪掉（守城的正是名冊裡的人）
  armyId='B1' → fought.side === 'B' ⇒ 不 absorbArmyPeople（R244 的敵將防護）
returnGeneralsToCity / handoffCapture
  BattleRoot 的還人塊用 `this.launch?.defend !== true` 擋掉守城戰 ⇒ 一個人都不寫回
回大地圖 seedRuntimeOfficers()
  ownedCityNames(樂陵)：roster 空 + takenOver 有記錄 ⇒ return [] ⇒ 名冊永遠補不回來
```

結果 `save.roster === {}`：這批將既不在城、不在兵團、不在圍城快照 —— 出征列表、名冊、守城候選全部查不到。
與此同時 `takenOver` 把劇本表保底也關了，所以連「重新開局」都補不回來。

**R244 之前**同樣丟人，只是原因不同（那時沒有 `returnGeneralsToCity`，也沒有 `takenOver`）；R245 讓「攻城勝利」好了，守城勝利仍然壞。

## 2. 四處修法（R246）

| 檔案 | 改動 | 為什麼 |
|---|---|---|
| `game/cocos/assets/scripts/GameState.ts` | `if (won) { ... if (!defend) markCityTaken(save, city); }` | 守城贏不是「打下城」：名冊裡是自己人，不能整城刪、不能記接管 |
| 同上 | `else if (defend)` 分支補：`delete lostRoster[city]`、`lostState.officers = []` | 守城輸了城易手，名冊與守將快照不能再掛我的人（面板會把敵城當我城） |
| 同上 | `absorbArmyPeople()`：落城/還人時 `delete save.generalStatus[name]` | 打過仗還活著＝沒死沒俘；否則名冊自愈與 `Ledger` 的 `isGone` 過濾會把活人當屍體剔掉 |
| 同上 | `handoffCapture()`：先撤存活者的舊生死判定，再交給 `Ledger.handoffCapture()` | `Ledger` 用 `isGone` 過濾存活者，舊局的錯誤判定會讓剛打贏的將進不了新城 |
| `game/cocos/assets/scripts/BattleRoot.ts` | 還人塊改成三分支：`defend ? (won ? 還本城 : 撤到 owned[0]) : (won ? handoffCapture : 回出發城)` | 守城勝利要把存活者寫回本城；守城失敗把殘部撤到還握著的城，不能原地蒸發 |
| `game/src/core/run_scoped.ts` | `RUN_SCOPED_KEYS` 增 `generalStatus` / `takenOver` / `siege` | 換局不清這三個 ⇒ 新局繼承上一局的「死/俘」判定（同名將被自愈剔掉＝開局將都沒了）、接管標記、圍城快照 |

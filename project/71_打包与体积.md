# 打包与体积（R82 批次）

> 本轮第一次**真正跑通 Cocos 构建**并产出可上传的微信小游戏包。以前 `project/44` 说「Cocos 三屏可跑」但**没人跑过构建**（`project/66` 的 C12：`cocos-build/web-desktop` 只有 23 个文件、缺 res bundle）。

## 1. 怎么跑

```powershell
cd F:\sanguo
Remove-Item Env:\ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue   # 残留会让 Creator 退化成 node 解释器
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build_wechat.ps1 -AppId wxf631d432ca7abcee -Mode upload
```

- `-Mode preview`：资源内嵌，给「扫码预览」用（主包必然 > 4 MB，不能上传）。
- `-Mode upload`：资源切到 `subpackages/res/`，主包只剩引擎与代码 —— **这个才能上传**。
- `-SkipWeb`：只重打小游戏包，不重建 web-mobile。
- 日志落在 `work\build-logs\{wechatgame,web-mobile}_YYYYMMDD_HHMMSS.log`；脚本以日志出现 `build Task (<platform>) Finished` + 产物目录存在为成功判据（CLI 的 exit code 不可信，本次实测 exit=0/1 都与结果无关）。

## 4. 音效：本轮仍未进包（但结论变了）

`build_wechat.ps1` 默认剔除 `assets/bundles/res/audio`（**16.07 MB / 109 档**），脚本注释的理由是「Cocos 版脚本里没有任何引用」。

**这个前提本轮已经不成立**：`w1-cocos-assets` 新增的 `AudioHost.ts` + `BattleRoot.ts:229/235` 会加载地形 BGM 与底噪。也就是说现在的包**有音效代码、没有音效文件**（播放会静默失败）。

三条路（**待用户拍板**）：

1. **保持剔除**（现状）：包 15.72 MB，Cocos 版无声。要不出声就别播（`AudioHost` 找不到 clip 时静默）。
2. **只留 3 首**（04/05/06，约 3 MB）：总包 ~18.8 MB，能进 20 MB，有声。
3. **走 CDN**：`-Mode remote -Server https://…/sanguo/`，`res` 不进包（包里只剩 1.89 MB 主包），音效与 4 组被移出的资源都能放 CDN，代价是要维护 CDN 与首次加载。

注：web 版（`game/web`）的音效不受影响，`assets/audio` 16.08 MB 仍在。

## 5. 没验证到的（重要）

1. **Cocos 运行时渲染没验证**：`game/cocos-build/web-mobile/index.html` 用 headless Edge 三种参数组合（含 `--enable-unsafe-swiftshader`/`--use-angle=swiftshader`/`--ignore-gpu-blocklist`）截出来**都是纯白 5780 B**。可能是 headless 下 WebGL 不可用、也可能是构建产物真的起不来 —— **必须在微信开发者工具或真机上点一次预览才能定论**。
2. 微信开发者工具没装/没跑，所以 `dist/wechat-upload` 只是**通过了脚本的静态校验**（主包 ≤4 MB、总计 ≤20 MB、`game.json` 首字节 `0x7B`、声明了 `subpackages/res`、`subpackages\res\game.js` 存在、AppID 已注入 `wxf631d432ca7abcee`），**没有真机扫码**。
3. 三个新表现层（`AudioBus/AudioHost/BattleBg/BattleWeather`）与重同步的 core 都只有 tsc + node 逻辑验证，没有在 Creator 里跑过一帧。
4. `res/manifest.json` 是旧的（写 564 档 / 29.7 MB，实际 2838 档 / 13.83 MB），无代码引用，未重生成。

## 6. 结论

- 「能不能出可上传的包」这件事**已经证明可行**：`dist\wechat-upload` 15.72 MB，主包 1.89 MB。
- 但**「Cocos 版能不能玩」仍未证明** —— 卡在两件事：①内政页/物品页面板（`project/69`/`project/70` 进行中）②没人真机跑过。
- 下一次构建时，请先确认 `res` 里该有的组都在（face/items/audio 视决策），再跑 `-Mode upload`，最后在微信 IDE 里点「预览」。

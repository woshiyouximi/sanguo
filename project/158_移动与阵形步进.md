# 158 · 移动与阵形步进：从「连续速度」改成原作的「行动 tick 抽格」

> 上游证据：`project/155_部队指令语义.md`（465 行，地址级反汇编，全部 `[确认]` 除注明）。
> 本轮只改内核移动结算，**没有**动 `game/web/**`、`game/cocos/**`、`game/src/core/smartscript/**`、`game/data/**`。
> 结论：原作没有速度倍率。所有单位共用一套 `[u+0x34]` 行动计时；到点那帧按权重抽一个方位、
> 试一个落点、**逻辑坐标直接改一格**（瞬移），再用 40 帧把像素滑过去。旧代码的
> `MOVE_PER_TICK=0.09`（≈2.7 格/秒）比原作快 3.6×，且 `ARMY_MOVE_SPEED`/`RUSH_SPEED`/`RETREAT_SPEED`
> 都是本作自造的倍率概念，本轮全部删除。

三条全局规则：

1. **行动闸门**（`0x43B574`）：`--u.cd`，`>0` 直接 return（不动也不打）；归零那帧才行动，行动后 `cd = actionIntervalOf(u)`
   （40 帧；`status & 0x4000` 时 46 帧）。实现：`battle.ts` `step()` 主循环。
2. **能打就不走**（`0x43BD64 == 1` 才走，否则同 tick 走攻击序列）：`step()` 里先算 `adjacentEnemy()`（切比雪夫格距 ≤ `ENGAGE_RANGE`），
   有敌 ⇒ 只 push 攻击 intent、`continue`，**不抽格**。实现：`battle.ts:2036` 起。
3. **格占位互斥**：
   - 第一轮 `0x43B467`：界内 + 该格没人（`occ` 里没有）；
   - 第二轮 `0x43C20D`：空格 → 落；界外且撤退态 → `0x43BFE7` 离场（`{exit:true}`）；敌格（`other.side !== u.side`）→ 拒；
     `other.lastActTick === world.tick`（本帧刚动过）→ 拒；`other.status & 0x1001` → 拒；否则请友军让位（`vcall`0x4c`(obj,2,0)`）
     再复查占位，成功才落；
   - 两轮都空 ⇒ 原地（`0x43C084` 吸附格心）。
   实现：`chooseStepCell()`（`battle.ts`）、`yieldFriend()`、`buildOccupancy()`。

## 五、没做到的 / `[推测]`

1. **主将退却间隔的等级修正未做**：`0x43B574` 在 `0x4000` 且主将时还有
   `u+0x34 += 2*((敌主将+0x40) - (本方主将+0x40))`（`+0x40` 疑为等级/兵力，`project/155 §2.1` 记为 `[确认]` 的读法但字段语义未定）。
   本作 `actionIntervalOf` 只给固定 46。影响：撤退中的主将行动频率在双方等级差大时略有偏差。
2. **`army+0x64` 分支未实现**（`0x43C921` 的 ②）：全库找不到非零写入者，判定**不可达**，属 `[推测]`。
   若后续反汇编找到写入点，加在 `cmdStepPlan` cmd1 的分支 ②。
3. **`0x43BFE7` 离场字段细节 `[未解]`**：本作只落成「删除单位 + `fled` 判定」，退出瞬间的像素/朝向字段没有还原。
4. **像素抖动未实现**：`0x43BE42` 在 `jitter==0` 时给落点加 `rand()%0x30-0x18` / `rand()%0x24-0x12`
   （±24px/±18px 的格内随机偏移）。本作 `slide` 落在格心，渲染层（`battleView.ts`，冻结）因此是规整对齐的。
   属视觉 `[新设计]` 差异，不影响逻辑格。
5. **`defaultStepPlan` 是兼容兜底 `[新设计]`**：原作默认命令字 0 = 待機，不会自动冲；本作旧局/旧测试依赖「无命令也会推进」，
   故 `armyStepPlan` 在「从未下过令」时回退到「朝最近敌一格」的默认计划。一旦玩家下过任何命令，就完全走命令字语义。
6. **PRNG 流不同**：原作 `0x4922FC/0x492300` 的具体 LCG 未还原，本作用 `mulberry32(seed)` 走同一 `rand()%n` 接口 ⇒ **分布**一致、**逐帧序列**不同。
7. **上移/下移的屏幕朝向 `[推测]`**：`0x43CA7B` 是 `(0,+1)`，而原作像素 `py = gy*0x48+0x24`（y 越大越靠下）。

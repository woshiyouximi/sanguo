## 2. [A2] 的三条链（本次把口径写死）

音效号必须 == 技能 `fx_dir`，且链必须是**静态可追**的：

- **(a)** 技能 → 特效函数 → `CreateXxx`（depth≤4）里 `PUSHS "mNNNsndNN"` + `SYSCALL 0x301`；
- **(b)** 技能 → 特效函数里 `PUSHI <ThingID>` 生成物件 → `THINGS.INI` 该物件动画串带 `$mNNNsndNN`；
- **(c)** 同 (b)，但物件动画串里是 `!nnnn` 回调 → 回调脚本函数（`id=0x…` == nnnn）里播音。

为什么这 24 条必须靠 (b)/(c)：**dirs 004/005/007/010/033 的 m 音串在 MAGIC.SO 里出现 0 次**（`m004snd01:0, m005snd02:0, m005snd03..05:0, m007snd01:0, m010snd01:0, m033snd01:0, m033snd02:0`），(a) 在构造上就不可能；旁证是同目录的 `m005snd01`(BigThunder)、`m007snd02/03`(FireStoneExplode/StoneExplode) 各有 1 次。所以这些音只能是物件层播的，取证方向唯一。

# 13 · 音频接入

音效取自 `extract/pak/SOUND/*.WAV`（99 个 / 5.92 MB）；BGM 取自原版安装目录
`…\三国群英传2 修正版 1.05+\MP3\01..17.mp3`（17 首 / 64.22 MB，MPEG1 L3 256 kbps 44100 Hz）。
那个目录是用户的原始安装，**全程只读，没有改动**。机器上没有 ffmpeg，转码用 Python：
`wave` + `numpy` + `miniaudio`（解码）+ `lameenc`（编码）。

## 1. 交付物与用法

`tools/export_audio.py` 一条命令重出全部资源（`--tier hi|mid|lo|mini|tiny`、`--out`、`--tracks all`）；
`game/web/audio.js` 播放模块（无依赖、普通 `<script>`，API 见 §4）；产物在 `game/web/assets/audio/`
（`index.json` + `sfx/*.mp3`×99 + `bgm/04,05,06.mp3`）；`game/web/serve.mjs` 只加 `.mp3`/`.m4a` 两行 MIME
（原来会退回 `octet-stream`）；`game/favicon.ico` 见 §7 末条。

用法：`python tools/export_audio.py`（hi 档，发布用）、`… --tier lo --out D:\x`（另出对比档，不覆盖）、`… --tracks all`（17 首全转，默认只转地形用的 3 首）。

## 3. BGM ↔ 地形

`Sango2.exe` 有格式串 `mp3\%02d.mp3`（`0x05315B`）⇒ **`[TERRAIN].SoundTrack` 的数字就是文件名编号**。
`SANGO.INI` 12 段 `[TERRAIN]`（行 81–212）取值只有 4/5/6，所以 12 个地形只用 3 首曲子：

| 1 | 城 | 5 | `05.mp3` | 7 | 森林 | 6 | `06.mp3` |

## 4. 播放 API（`window.SG.audio`）

| 调用 | 行为 |
|---|---|
| `bgm(name)` | 切曲，300 ms 交叉淡入。`name` 可 `'terrain:0'`、`'terrain'`（读 `?terrain=N`，缺省 0）、`4`/`'04'`/`'04.mp3'` |
| `sfx(name, {volume})` | 8 个 `Audio` 轮转池；走语义别名（`hit`→`hit01`、`spell`→`m005snd01`…共 22 条） |
| `mute(bool)` / `toggleMute()` | 静音开关，返回当前状态；静音时 `sfx()` 直接 return，不建元素 |
| `unlock()` | 微信/iOS 手势解锁；首次 `pointerdown`/`touchstart`/`keydown` 已自动调 |
| `stop()` / `setBgmVolume` / `setSfxVolume` / `warm([names])` / `state()` | 辅助（`state()` 可查 `bgm`/`pool`/`indexLoaded`/`sfxCount`） |

预加载：`index.json`（3.9 KB）在首帧后的 `requestIdleCallback` 才拉，不占首屏；MP3 全懒加载。
`index.json` 读不到也不影响播放——`audio.js` 内置同样的地形表和别名表兜底。

`main.js` 三行钩子（都在原有函数体内，逻辑全在 `audio.js`）：① `startBattle()` 末尾 `window.SG?.audio?.bgm('terrain')`；
② `doCast()` 里 `cast()` 成功后 `sfx('spell')`，`result.killed > 0` 再 `sfx('hit')`（同一行）；③ `endBattle()` 里 `won/drew`
之后 `sfx(won ? 'victory' : drew ? 'success' : 'defeat')`。`campaign.html` 三行：`<script src="./audio.js">`、`bgm('terrain:0')`、`pointerdown → sfx('click')`。

## 6. 微信 / iOS

- **自动播放**：微信/iOS 必须用户手势。`audio.js` 首次 `pointerdown`/`touchstart`/`keydown` 自动 `unlock()`；被拦的 `play()` 直接吞掉（`NotAllowedError` 只 log 不抛），手势来了补播，不会漏。
- **切后台**：`visibilitychange` 里暂停 BGM，回前台若没静音再续播；不暂停会一直占音频焦点。
- **静音开关**：`SG.audio.mute(true)` 同时管 BGM 和音效池，建议在设置页持久化到 `localStorage`，启动时调一次。

## 7. 未解 / 已知限制

- **15 个无数据出处、纯按名推断**：`att01` `att02` `att03` `att05` `att06` `att08`、`accept`、`bg07a`、`death`、`death3`、`defense2`、`flaysword`、`silence`、`yell02`、`yell04`。它们在 exe / SANGO.INI / THINGS.INI / MAGIC.SO / SYSTEM.SO 里都没有字面量（exe 只有菜单键名 `ACCEPT`，非音效引用；`bg07a` 在 SANGO.INI 里是 `Background = BG\BG07A.SHP` 背景图）。
- **8 个 m 目录没有 fx_dir 记录**（`m000/011/019/027/032/036/038/041`），技能名对不上，只标 [推测]。
- **17 首 BGM 里 14 首用途未知**：只逆出地形用的 4/5/6，标题/大地图/剧情的曲目号不在 INI 里，可能写死在 exe 代码中。
- `game/favicon.ico`：验收时每页都有一条 `/favicon.ico 404` 的 `Failed to load resource`，与音频无关但会污染
  console 判定，补了一个 649 B 的 ico（不动任何 HTML）。

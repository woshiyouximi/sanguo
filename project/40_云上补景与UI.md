## 3 三类结论

### 3.1 战场背景 12/12 ADOPT

`城·攻城 / 城·街巷 / 城·城墙 / 船上 / 草原 / 平原 / 山地 / 森林 / 雪原 / 沙漠 / 關卡 / 長城`，
与 `data\terrains.json` 的 0–11 一一对应（0/1/2 是三个"城"，故给三种构图）。

- 全部 45° 俯视，画内无单位、无旗帜、无文字，中间留大块空地放站位与 UI。
- 三层已切成独立 PNG：`project\art_ref\cloud_env_v1_layers\terrain_XX_{far,mid,near}.png`（832 宽带 alpha，
  切在 y=20%/48% 带 26 px 羽化），演示页 `work\env_parallax_demo.jpg`。
  **机械 y 带 ≠ 手切轮廓**：几张图的地平线正好压在 20% 处（`terrain_00` 切在城墙顶上沿），
  真要上线得按图手切 mask，这版只证明"能三层异步滚动、错位 90 px 还能合回去"。

### 3.2 内政大殿 6/6 ADOPT（`hall_03` 偏弱）

`高堂 / 军帐 / 郡府 / 边关 / 水寨 / 民居`，全部有坐席案几、中央留白、无人物无文字。
最稳的是 `hall_01 高堂`（朱漆柱 + 三级台阶 + 主位长案 + 蒲团）与 `hall_05 水寨`（水榭立柱 + 泊船远景 + 两侧坐席），
中央都留出干净的压字区。两张偏弱：`hall_03 郡府` 主位被画成带帐的床（偏内室）、
`hall_04 边关` 是土坯营房（挂甲胄与弓，气势不足，凳子偏多）。都能用，但若哪天要"六宫齐全"，
优先重跑这两张（改 prompt：郡府去掉帷帐、边关换成夯土关楼内景）。

## 4 踩到的坑

1. **`negative_prompt` 原本是死的**：`cloud\run_batch.py` 的 `build_t2i()` 把
   `TextEncodeQwenImage21.negative_prompt` 硬编码成 `""`，CSV 的 `negative` 列对 t2i 完全无效，
   首张 `terrain_00` 因此画出士兵、骑兵、旗帜。已改成读 CSV 的 `negative`（本地 + pod 同步），
   并把正向 prompt 里"战场/士兵/马匹/旗帜"这些诱导词删掉换写成"空旷无人"。
   **这是本轮最值钱的修复，之后所有 t2i 批次都受益。**
2. 状态 `running` ≠ SSH 可连，Migrating 结束后还要再等约 30 s。
3. `/model` 是只读共享模型缓存（50 TB UPFS），写不进去；下载只能落 `/workspace`（50 GB overlay）。
4. tar 回传后必须用 Python `tarfile` 解（中文文件名）。
5. UI 底是深灰平底，用"到背景色的软阈值 + 1–2 px 羽化"抠透明（Pillow，没装 rembg），阈值按四角背景色距离 p99 自适应；16 张里 13 张边缘干净，`frame_bronze` / `popup_frame` / `scroll_*` 的镂空区都正确透明。

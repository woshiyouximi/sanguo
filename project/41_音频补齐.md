## 2. 映射覆盖率（验收口径）

脚本：`work/snd_map.mjs`（读 `data/magics.json` + `game/web/assets/audio/sfx/` 实际文件名），产物 `work/snd_map.json`。

```

```

- 规则：`dir = fx_dir_primary || fx_dir[0]`；优先 `m<dir>snd01.wav`，缺则取该目录内最小编号（本轮 fallback=0，全部命中 snd01）。
- **9 条静默**全部集中在两个目录：`006`（火箭/火箭烈/火箭天襲/飛矢/亂飛矢/飛矢烈震，6 条）与 `024`（後伏連兵/後伏兵陣/後伏軍陣，3 条）。
  `extract/pak/SOUND` 里只有 `M000–M041` 且**根本没有 M006\*/M024\*** —— 原作这两族技能本来就没配音，不是我们漏转。
- 查不到就 `return`，**不退回统一音**（37c 已确认 `spell` 这种"一个音顶全部"就是 93 个装了没用的根因）。

## 3. 命中 / 受击 / 格挡的接法

- 时机依据：普攻命中 = EXE `0x43E07C push "HIT01"`；受击 = `THINGS.INI` 的 `Pain = …, $Hit01`（120 处）；格挡 = `Defense = …, $Defense`（120 处）。
- core 只暴露 `world.stats.{attacksA,attacksB,hitsA,hitsB}`，**没有单独的格挡计数** ⇒ 每逻辑 tick 取增量：
  `hits = ΔhitsA + ΔhitsB`（放 `hit01`）、`blocks = max(0,ΔattA-ΔhitsA) + max(0,ΔattB-ΔhitsB)`（放 `defense`）。
- 节流（`main.js` 的 `[[AUDIO]]` 块）：① 同一 tick 最多 2 声（`SFX_TICK_MAX`）；② 同名音效 60 ms 内不重叠（`SFX_GAP_MS`）。
  不节流的话 100 人混战每 tick 有几十次命中，会炸成白噪音。
- 施法那行原来的 `sfx('spell')` + `killed>0 → sfx('hit')` 已删：技能音改由第 1 条按目录放，击杀不再借用普攻命中音。

## 7. 调试开关与验收证据

- `?sfxdbg=1`：左下角打印 `sfx: N  名字×次数` + `bgm: xx.mp3 vol 0.45  amb: bg0Xa vol 0.16`；`?bgmdbg=1` 再加一行"已装 10/17 清单 + 曲目用途"。
- `?auto=1&sim=240&freeze=1&sfxdbg=1` = 无头截图标准姿势（同步跑 240 tick，`tickBattleSfx(0)` 关掉 60 ms 间隔但仍然 ≤2 声/tick）。
- 证据：`work/audio_battle.png`（`sfx: 94  defense×63 hit01×31`、`amb: bg03a`）、`work/audio_city.png`（`failure2×2 success×1`、`bgm: 13.mp3`）、`work/audio_bgm.png`（`bgm: 17.mp3` + 10 首清单）。
- 无头浏览器里 `bgm` 一栏会显示 `(paused)`：Chromium 的 autoplay 策略拦掉了没有手势的 `play()`，页面上的真实点击会解锁——不是代码问题。

## 8. 没做成 / 已知限制

1. **节流是"每 tick ≤2 声"，不是按人次混音**：100 人混战听感仍偏密，要更稀就调 `SFX_TICK_MAX`/`SFX_GAP_MS`（一处常量）。
2. **格挡是代理指标**：core 没有 block 计数，用 `attacks-hits` 代替，会把"射空/未命中"也算成格挡；要精确得改 `game/src/core/battle.ts`（本轮硬边界禁止）。
3. **底噪的地形映射是 [推测]**：`BG03A/04A/08A/09A` 在 EXE 里搜不到字符串，`SYSTEM.SO` 只证明"进战场会铺底噪"，没证明"哪个地形配哪个"；现按材质分桶（城/水/草原→03A，山地/森林/長城→08A，雪原/沙漠→09A）。
4. **战后不回菜单曲**：结算后仍停在战斗曲，没有淡到 03；结局请求的 18 号曲本来就没有 `18.mp3`，未接。
5. **`game/dist` 未重编**：`main.js` 只用现有 `dist/core/battle.js` 的 `stats`，没碰 `game/src/**`。

# 214 · 原生包黑屏与「新局误弹招降」

**一句话**：Cocos 原生包黑屏是 `new URL` 在 jsb-adapter 里崩掉 main bundle；「新局弹处置張角」是 `SurrenderPanel` 没传剧本/守将、恒用剧本 0 的平原守将；两处都修好，并顺手把「新局先开内政」「顶栏纪年」「底部内政入口」对齐 web。

改前 → 改后

| 现象 | 根因 | 修法 |
|---|---|---|

## 坑

1. `@ccclass` 装饰器必须紧贴 class：往 `export class` 前插函数会把装饰器挤到函数头上 → `TS1206 Decorators are not valid here`。
2. `game/cocos/assets/scripts/core/roster.ts` 不在 `sync_core3` 清单里（镜像 mtime 还停在 11-25）——core 新导出要加在会被同步的文件，否则 `tsc -p cocos` 报 `has no exported member`。
3. 测试里 `import '../cocos/assets/scripts/xxx.ts'` 会撞 `TS1287`（cocos 目录没有 `"type":"module"`）——纯逻辑放 `game/src/core/**` 再测。
4. `adb shell input tap` 在 MuMu 上坐标不稳（底部按钮要 2340 而不是 2410），判定状态前先 `am force-stop` 重启并对照 `databases/jsb.sqlite`（`work/native_debug/dump_save.py`），别只信一帧 screencap。
5. `tools/*.ps1` 用 `edit` 改完会掉 UTF-8 BOM，`powershell -File` 按 GBK 读整篇 mojibake——改完必须补 BOM 并 `[Parser]::ParseFile` 验 `parseErrors=0`。
6. `build_native.ps1` 头上有 `#Requires -Version 7.0`，必须用 `pwsh` 跑（`powershell` 5.1 直接 exit 1）。

## 还没修（实机新发现）

- **攻城战进编成屏时主将变成守方**：截图 `work/native_debug/r214d_battle.png` 里目标 樂陵、出发城 平原，但主将卡是「張角 · 黃巾 · 守軍 110 兵」，将列也全是守城守将（張角/廖化/管輅/裴元紹/蔣義渠/杜遠）⇒ `GameState.setDeployFrom/takeDeployFrom` 在 DeployRoot 里被读早/被清，或 關卡分支抢了 `officersOf(target)`。
- **出征只带 5 兵**：`dispatchArmyTo` 没有让玩家选兵（web 的 deploy 会按上限给），戰報写「平原 → 樂陵 (5 兵, 1 個月)」。
- `magic_so 預加載失敗：Cannot read properties of undefined (reading 'toLowerCase')`（非致命，法术退化成占位）——同一类 `URL` 垫片问题，尚未定位调用点。
- 调色板守卫 `work/palette_guard/palette_guard.ps1` 仍跑不通：`cdpweb.mjs:108` 的 `evaluate(expression)` 只收字符串，`steps_palette.mjs` 传函数。

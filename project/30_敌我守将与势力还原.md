# 30 敵我守將與勢力還原

用戶反饋「敵人壓根沒有知名武將」：舊接線敵將一律叫「守將」、屬性用 `str = min(100, 50 + floor(DEFENSE/8))` 代理。本輪按原作數據還原勢力、太守/軍師、守將名單，只新增 core 與 data；html 三處接線只給 diff（行號＝當前文件），不應用。

## 1 數據來源（既有字段，沒有新造數值；`i`＝劇本下標 0..4）

- 勢力 / 太守 / 軍師：`cities[].KING` / `MAJOR` / `WISE`（`""`＝無主）← `game/data/scenarios.json`（5×60 城）
- 守將名單：`generals[].city_by_times[i] == 城名` ← `game/data/generals.json`（401 行）；狀態取 `status_by_times[i]`（登/野/未）；忠誠取 `Loyal`（僅「盜賊」用大寫 `LOYAL: ""`）
- 守軍沿用舊公式 `min(floor(POPULATION/2500)+110, 600)`；`CITY`/`Status` 是第 1 劇本的冗餘列，**一律不用**（用了第 2..5 劇本的守將會集體穿越），野將同樣收進名單
- 第 1 劇本 12 城的 `KING` 是數字 `1..12`（易京/樂陵/界橋/壺關/定陶/都陽/官渡/筑陽/長板/建平/赤壁/合肥，連續遞增＝轉換殘留），`kings[]` 也無可靠映射 → 寫 `""`，否則 UI 會出現「勢力 1」
- 401 行中只有「盜賊」沒有 `city_by_times`；`MAJOR`/`WISE` 全部能在本城 `officers` 裏查到（腳本斷言，5 劇本 0 例外）

## 2 `game/data/garrison.json`
`work/build_garrison.py` 生成。結構：`[{ "scenario": 0, "cities": { "襄平": { "owner": "", "major": "", "wise": "", "officers": [{"name","str","int","loyal","status"}], "garrison": 141 } } }, …]`；5 條 × 60 城（空城也留，`officers: []`），緊湊 JSON，**87,547 字節**；`officers` 全收、按 `STR+INT` 降序（同分按碼位，保證字節穩定）。
劇本 0..4 的「有將城/空城/武將記錄/owner 非空/major·wise 非空」：`0 34/26/142/21/21 · 1 39/21/189/27/27 · 2 40/20/211/36/36 · 3 43/17/231/35/35 · 4 43/17/238/41/41`，合計 1011 條記錄、跨劇本 400 名武將。

## 3 API（`game/src/core/garrison.ts`）
```ts
type Officer = { name: string; str: number; int: number; loyal: number; status: string };
type Garrison = { owner: string; major: string; wise: string; officers: Officer[]; garrison: number };
garrisonOf(data, scenario, cityName): Garrison | null        // 只有「城不存在」才 null
defendersOf(data, scenario, cityName, count = 3): Officer[]  // 前 N；N≥2 時太守必入選
pickCommander(officers, exclude?): Officer | null            // STR+INT 最高，可排除
battleSetup(data, scenario, cityName, soldiers): { enemyGeneral: { name; str; int }; enemyTroops: number; enemyOfficers: Officer[] }
```
`data: GarrisonData extends GameData { garrison?: unknown }`；舊數據沒有 `garrison` 時用 `generals[].city_by_times` 現算兜底，與 `garrison.json` **逐城 deepEqual**（測試覆蓋 300 城）。`enemyTroops = min(100, max(60, round(garrison/6)))` 且不超過守軍；無將時 `{守將,0,0}`。四個函數都不拋異常，取不到給 `""`/`0`/`[]`/`null`。

## 5 口徑與遺留

- `defendersOf(..., 1)` 只給最強的那名（否則洛陽會派太守何進 74+49 而非曹操 87+92）；N≥2 才保證太守入選，頂掉第 N 名後重排降序，「≤N 且降序」不破。`battleSetup` 的主將取**最強**守將，太守只負責上陣。
- 未改：`game/web/**`、`battle.ts`、`cocos/**`、`proto/**`、頂層 `data/`。`dist/` 要由 lead 的構建流程產出 `dist/core/garrison.js`，否則上面三個 import 會 404。

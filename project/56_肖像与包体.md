## 3. 第 2 步：原作 FACE 图集（核心交付）

### 3.1 目录结构

```
game/web/assets/face/
├─ index.json                32,620 B   名字 → {n, face, sex_hint}
├─ full/000.webp … 400.webp  1,652,400 B (1.58 MB)  100×120 原尺寸，400 张
└─ thumb/000.webp … 400.webp   302,154 B (0.29 MB)  30×40，400 张
```

- 文件名是 **3 位零填充 + `.webp`**（`007.webp` ↔ `FACE007`），不用 349 这种裸数字，方便字符串排序和肉眼对号。
- `full` **保持 100×120 不缩放**（预算 1.8 MB，实到 1.58 MB）；`thumb` 30×40 按页面真实的 **cover 规则**裁切后再缩（`object-position: 50% 14%`，与 `items.html:70` 的 `.pick .it img` 一致），不是压扁。
- 合计 **1.90 MB ≤ 2.5 MB**，`full` / `thumb` 两项小预算也都达标（脚本每次跑完自带预算检查）。

### 3.2 index.json 契约与片段

- `sex_hint`：只有这 6 名女性写 `"F"`（名字白名单 + `face_women.png` 逐张肉眼确认），其余 394 个写 `"?"` —— `generals.json` **没有性别字段**，不硬断言 `"M"`。

fallback 已经被 `face_map.js:410`（`if (!n) return "assets/hero/" + ...`）和 `face_map.js:418-424` 的 `error` 捕获兜住：face 缺图 → 自动退到 `thumb` → 再退到 `hero`。**`main.js` 那侧唯一要小心的是竞态，见 6.4。**

### 6.3 如果你更想用 `index.json`（我提供的契约）而不是 `face_map.js`

两套是同一份事实的两份拷贝（已交叉校验一致）。`index.json` 的好处是它跟图片一起生成、`--verify` 保证同步；`face_map.js` 的好处是零网络请求、同步可用（没有竞态）。要用 `index.json` 就这 5 行：

```js
// ① 懒加载一次名字→编号表（assets/face/index.json 的 faces 字段）
let FACE_OF = null;
fetch('assets/face/index.json').then(r => r.json()).then(j => { FACE_OF = j.faces || {}; });

// ② 名字 → 图 URL；表还没到时 / 名字不在表里 → 退回现用 AI 立绘（永不出现空图）
function faceUrl(name, kind = 'full') {
  const e = FACE_OF && FACE_OF[name];
  return e ? `assets/face/${kind}/${String(e.n).padStart(3, '0')}.webp`
           : 'assets/hero/' + encodeURIComponent(name) + '.webp';
}
```

三层 fallback 都是现成行为：① `index.json` 404 / 还没 fetch 到 → 全退回 hero，跟今天一样；② 名字不在表里（`main.js:594` 的 `守將` / `來犯之將` / `張角` 这类合成名）→ 退回 hero；③ 文件缺失 → 各页已有的 `img.onerror` 藏图（`deploy.html:338`、`items.html:353`）。

### 6.4 竞态：只有 `main.js` 需要处理

`main.js` 的 `loadPortrait()` 按名字缓存（`if (state.portraitName === name) return state.portrait;`）。如果首帧在 `fetch` 回来之前就画了，HUD 会**一直停在 hero 图上不换**。用 `face_map.js`（同步 `<script>`）不会有这问题；非要用 `index.json` 就这么收尾：

```js
fetch('assets/face/index.json').then(r => r.json()).then(j => {
  FACE_OF = j.faces || {};
  state.portraitName = null;   // 让 loadPortrait 重新取一次
  loadPortrait(); draw();
});
```

`deploy.html` / `items.html` 是 DOM 页，每次渲染都重设 `img.src`，在 then 里再调一次 `renderGen()` 即可。

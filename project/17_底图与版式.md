# 17 · 底图与版式

> 本轮目标：把"纯深色渐变 + 文字按钮"的四个页面补上"画"（用户原话："我看地图和Ui都没有底图"）。
> 允许改动：`game/web/campaign.html`、`deploy.html`、`items.html`、`index.html` +
> 新建 `game/web/assets/bg/*.png`。**未改** `game/src/**`（视图层冻结）。

## 1. 结论先行

- 四个页面现在都有底图：大地图（原作整图占位）＋编成（案几）＋物品（兵器架）＋战斗顶部 HUD（军旗木纹）。
- **原作素材只作"开发期占位/对齐参照"**（1999 ODIN SOFT 商业素材，见 §6），发布前必须替换。
- 六张 AI 底图实测平均亮度 26–41（硬约束 ≤90），图内无任何文字；地图占位图被 `.58→.72` 深色蒙版压住，细节不可辨。
- 顺手修掉一个既存布局 bug：`fit()` 只 `transform:scale` 不补偿布局盒，1200×900 下标题被顶出视口（§7）。

## 3. 原作的信息层级（对比结论）

1. 原作是**亮底深字**：路是亮橙、河是饱和青蓝、海岸线硬边，整图平均亮度约 140；我们做的是**暗底白字**，方向相反 → 必须压暗降饱和，否则白标签读不出。
2. 原作**文字从不直接压地图**，一律压在纯色区（黑底金字、深蓝底白字）；地图上的城名另带深色拖尾 → 我们的白字压底图，必须给暗蒙版或文字阴影。
3. 原作底图**不含名字/格线/城图标**，城市只由"道路交叉口节点"暗示；我们的城点+城名是净增信息层，所以底图必须退到"背景"。
4. 原作框体是**厚木框（10–22px）＋ 2px 金边**双层结构；我们原来是 1px `rgba(255,255,255,.06)`，太薄没材质 → 本轮所有卡片改成 `rgba(16,20,26,.72)` + `1px rgba(216,179,106,.16)`。
5. 原作按"上暗（标题）→ 中亮（人物/事件）→ 下暗（选项）"竖向分段布局；`deploy_bg` 照此把控件区放上部暗场、案几放下部。
6. 原作战斗底是 **96px 高横条视差层**（不是全屏图），靠高饱和旗色区分敌我；我们的战斗页是竖屏单画布，只在页面层补 HUD 条（§5）。

## 5. 每页叠层参数（照此复现）

**大地图 `campaign.html`**
- `#stage` 背景三层：`url(assets/bg/map_bg.png) center top/cover` → `radial-gradient(120% 70% at 50% 0%,#1B2430,#0E1116 62%)` → `var(--bg)`（图缺失时自动落到后两层，不白屏）。
- `#mapwrap` 三层（自下而上）：`<img class="bgmap">`（`map_sheet.png`，四边 40px `mask-image` 羽化，`mask-composite:intersect`）→ `.bgveil`（`linear-gradient(rgba(10,14,20,.58), rgba(10,14,20,.72))` + `inset 0 0 72px 6px rgba(8,11,15,.42)`）→ `canvas`。
- `.bgmap` 用 `object-fit:fill`（**不是 cover**）：JS 的 `plotRect()` 已按 4:3 算出与城点完全同一矩形（`s=min(w/1280,h/960)*0.965`），宽高比一致所以 fill 不会变形；若用 `cover` 会裁掉边缘，青海/辽东的城点会漂出图外。
- `canvas` 在 `?bg=1`（默认）下**不再画夜色底纹**（原 `#11161D→#0B0E12` 的 `fillRect` 已包进 `if(!USE_BG)`）；`?bg=0` 回到旧的自绘夜色，方便对比。`?routes=1` 才画 116 条路线（底图已烘道路，默认关）。
- `#logbox` 由纯黑改 `linear-gradient(180deg,rgba(10,13,17,.9),rgba(11,14,18,.74))`，让衬底透上来。

**编成 `deploy.html`**：`#stage` `url(assets/bg/deploy_bg.png) center top/cover` ＋ `::before` `linear-gradient(180deg,rgba(8,11,15,.30),rgba(8,11,15,.40) 46%,rgba(8,11,15,.52))`；卡片 `rgba(16,20,26,.72)` + `1px rgba(216,179,106,.16)` + `0 10px 26px rgba(0,0,0,.32)`。
**物品 `items.html`**：同上，蒙版 `rgba(8,11,15,.38/.50/.62)`（这页字最密，压得更重）。
**战斗 `index.html`**：`header` 背景 `linear-gradient(180deg,rgba(10,13,18,.30),rgba(10,13,18,.66))` + `url(assets/bg/hud_bar.png) center/100% 100%` + `rgba(14,17,22,.94)` 兜底；`#hudbot` 用同一张图贴在画布下沿（高度 `min(64, innerHeight-r.bottom-4)`，`>18` 才显示，`pointer-events:none`）。**战场画布本身不贴图**。

## 6. 坐标对齐与版权口径

- 已验证：`game/data/scenarios.json[0].cities` 60 城的 `pos_xy`（x 88–1138 / y 84–860）就是 `CHINAMAP.png` 的像素坐标，逐点零错位（`work/bg_align_probe.py` → `work/bg_align_probe.jpg`）。所以 `make_map_sheet.py` 保留 1280×960 的画幅比例，`plotRect()` 按同一矩形摆放底图与城点。
- `map_bg_v2.png`（AI 重绘 4:3）构图接近但不精确：海岸线与河道位置差约 5–10% 画幅，直接换会让城点偏离道路节点。**替换方案**：要么按 v2 重新标定 60 城坐标，要么让 AI 按 CHINAMAP 做同构图重绘。
- 版权口径（lead 2026-11-24 确认）：原作素材（CHINAMAP / PALAIS / MENU / BG）**只能当开发期占位/对齐参照，不能作为发布资源**；占位只用在底图/背景层，且必须被 ≥.55 的深色叠加压到看不出细节（本页 `.58→.72`，实测压后整体 p50 亮度 35）。**不得**在任何界面使用原作 logo、人物立绘、UI 装饰纹样——`TITLEBG.png` 上有 logo 与 ©1999 ODIN SOFT，本轮**未**整张使用。

## 7. 顺手修的既存 bug

三个页面（campaign/deploy/items）的 `fit()` 原来只做 `transform:scale(s)` 并把 `body` 宽高改成 `750s×1334s`，但 `#stage` 仍是 750×1334 的 flex 子元素，溢出时 flex 居中把左上角顶出视口 → 1200×900 下标题整条被裁。改为：先把 `#stage` 绝对定位到 `((innerWidth-750s)/2, (innerHeight-1334s)/2)` 再 scale（`transform-origin:top left`）。750×1334 下偏移是 (0,0)，像素零变化。

> 本文所有"原作有没有"都来自 EXE 反汇编（`Sango2.exe` 682,496 B，VA 见 §1），不靠猜。

## 1. 原作音频架构（逆向实证）

| 通道 | 入口 | 谁在用 |
|---|---|---|
| 脚本平面音 | syscall **0x301** → host `0x420B77` → `0x4699A0` | MAGIC.SO 88 站 / SYSTEM.SO 15 站，**原作绝大多数音效走这里** |
| 脚本定位音 | syscall **0x300** → host `0x420B26`（带 obj 坐标）→ `0x469900` | MajorDeath 的 Yell03 / Horse02 |
| 动画帧钩子 | THINGS.INI 序列里的 `$名字` | `$Defense`×120、`$Hit01`×120、`$Horse01`×8、9 个技能烟火音 |
| EXE 硬编码 | `0x43E07C push 0x490294 "HIT01"`（普攻命中，函数 `0x43DDBF`） | **只有这 1 个** |
| BGM | `0x46CDA0(track)` → `0x453CE2` → `sprintf("mp3\%02d.mp3")`@`0x453CF6` → MCI | 18 个调用点（§3） |

- 路径拼接 `0x469520`：`"SOUND\"`(0x4A2C9C) + name + `".WAV"`(0x4A2C94)；取/建 DSOUND 缓冲 `0x468BA0`。
- **否定证据（重要）**：`ACCEPT`（64 处）、`DEATH`、`DEFENSE`、`SILENCE` 在 EXE 里的字面量引用都**不是放音**——`ACCEPT` 全是 `MENU\...` 资源名，`DEATH/DEFENSE` 是 THINGS 解析器 `0x436F4F` 的动作键名。所以"原作有个按钮音效叫 accept"这个假设是错的。
- **否定证据 2**：EXE 里没有任何 `att%02d` / `%s%02d` 这类拼名格式串（只有 `mp3\%02d.mp3`、`CITY%02d`、`PATH%03d`、`SAVES\SANGO%02d.SAV`），所以 attNN/yellNN 不是动态拼名，**本版 EXE 真的不引用**。

## 2. 音效 99 个（按用途分组）

### 2.1 技能/魔法音效（58 个，全部有出处）
- 触发：MAGIC.INI `SCRIPT=` → MAGIC.SO 函数 → `PUSHS "名字"` + `SYSCALL 0x301`。88 个站点、58 个不同名字。
- 命名规律：`mNNNsndMM` 的 **NNN 是 `SHAPE\MAGIC\NNN` 目录号，不是技能号**（上一轮已实证）。
- 代表映射（完整表见 `work\a_so_sfx2.py` 输出）：`Heal→m016snd01`、`BigThunder→m005snd01`、`Frozen→m013snd01`、`FireRing→m021snd01`、`BlackHole→m020snd01/02`、`CallDragon→m018snd01/02`、`ShootObject→m003snd01/02/03`、`HalfMoon→m001snd01`、`RunningBow→m019snd01`、`Tornado→m011snd01`、`Wall→m037snd01`、`QuakeSound→m040snd01`、`Interceptor→m041snd02`、`DemonDancing→att07 + yell01`、`Hurt/SmallFireBall*→hit01`。
- **我们的状态：58 个里 1 个被用**（`m005snd01` 当万能 `spell`）；其余 57 个技能音效全哑。

### 2.2 单位动作 / 技能烟火（12 个，THINGS.INI 钩子）
`$Hit01`×120（Pain 序列，=受击）、`$Defense`×120（格挡）、`$Horse01`×8（骑兵移动）、`$m004snd01`、`$m005snd02/03/04/05`（雷）、`$m007snd01`、`$m010snd01`、`$m033snd01/02`。
- **我们的状态：1 个被用**（hit01，且只在"施法且击杀>0"时响），11 个全哑。
- 注意：THINGS.INI **没有**按兵种/单位配 hit/yell 的字段，`Win/Attack/Death/Pain/Defense` 都是动画帧序列名，不是音效键——所以原作士兵死亡/攻击**本来就没有独立音效**（靠 Pain 的 hit01 + 技能音）。

### 2.3 系统 / UI（10 个，SYSTEM.SO）
`Rush01`（全体突击）、`SUCCESS`（搜索成功×4 / 招降 / 生子）、`FAILURE2`（搜索失败×2）、`VICTORY`（MajorDeath=战场结束）、`Yell03`+`Horse02`（主将死亡，定位音）、`BG03A/04A/08A/09A`（LoadingBattleMap，战场环境底噪）。
- **我们的状态：3 个被用**（victory/success/failure2），`rush01`、`bg03a/04a/08a/09a`、`yell03`、`horse02` 全哑。

### 2.4 用途未知（20 个，本版零引用）
`accept arrow att01 att02 att03 att04 att05 att06 att08 bg07a death death3 defense2 flaysword hit02 m028snd02 m039snd02 silence yell02 yell04`
- 推测（**仅供决策，没有证据**）：`att01–08` = 8 种兵种攻击音；`yell01–04` = 武将喊杀（yell01 被 DemonDancing 用、yell03 被 MajorDeath 用，说明这一组原本就是"喊"）；`death/death3/defense2/hit02` = 同类变体；`bg07a` = 与 03/04/08/09 并列的第 5 种环境底噪（07 号地图）；`arrow`/`flaysword` = 箭矢与劈砍；`silence` 0.1 s 占位；`m028snd02`/`m039snd02` = 技能第二段但 .SO 只引用了 `-01`。
- **决策建议**：这 20 个**不要删**（体积小、语义清楚），按名字接即可；`accept` 我们已经在当按钮音用——这算"我们给原作补的"，不是还原。

## 5. 体积与打包（首包 4 MB 约束）

| 项 | 现状 | 备注 |
|---|---|---|
| 99 WAV 原始 | 6,203,511 B（5.92 MB） | 采样率 8k/11k/16k/22k/44.1k 混杂，单/双声道混杂 |
| → `hi` 档 SFX | **2,823,730 B**（96 kbps 单声道 22.05 kHz） | 已入库，实测 |
| → `tiny` 档 SFX | 约 1.9 MB（32 kbps + BGM 24 kbps 22.05k 单声道） | 听感明显退化 |
| 3 首地形 BGM（hi） | **6,818,167 B**（128 kbps 立体声 44.1 kHz） | 04 2.65 + 05 2.14 + 06 2.03 MB |
| 当前总和 | **9,645,837 B**（9.20 MB） | 已超首包 4 MB |

- 17 首全量换算：@128k 立体声 **32.15 MB** / @64k 单声道 **16.07 MB** / @48k 单声道 22.05k **12.05 MB**；单首 @64k 单声道 0.55–1.33 MB。
- **建议方案（三层）**：
  1. **首包只放 SFX**：`hi` 2.82 MB + `index.json` 4 KB，余量 1.18 MB。BGM 一首都不进首包。
  2. **BGM 全部懒加载**：`audio.js` 已经是 `bgm()` 触发才 `new Audio()`，只需把 3 首地形曲也移出首包（现在是随包发的），改走 CDN/分包目录 `bgm/`，按需取。单首 @64k 单声道 ≤1.33 MB，进 4 MB 预算毫无压力。
  3. **补齐曲目按优先级分批**：先 03（菜单）、17（大地图），再 10–14（内政 5 档），最后 01/02/07/08/09/15/16（死曲目，**建议不装**，省 8 MB）。
- 若必须"全离线包"：SFX 用 `tiny`(1.9 MB) + 地形 3 首 @48k 单声道 22.05k（6.8×6/16≈2.55 MB）= 4.45 MB，仍差 0.45 MB ⇒ **4 MB 装不下全量，只能拆包**。

## 6. 最影响体验的 5 条（按性价比排序）

1. **战斗里只有 1 个技能音**：58 个技能音效全哑，所有战法共用 `m005snd01`。改法最便宜——`data/magics.json` 已有 `fx_dir_primary`，建 `mNNN→snd` 表，`main.js:885` 按技能查名即可，零新资源。
2. **普攻/受击完全没声音**：`main.js:885` 把 `hit` 绑在"施法且击杀>0"，而原作是每次命中 `HIT01`（`0x43E07C`）。战斗从"有节奏"变成"点一下才响一下"，这是手感最大落差。
3. **三个页面零音频**：`city.html` / `deploy.html` / `items.html` 没引 `audio.js`，内政、编成、道具全程静音。加一行 `<script src="./audio.js">` + 搜索/招降接 success/failure2 即可。
4. **战场环境底噪缺失**：原作进战场铺 `BG03A/04A/08A/09A`（6–14 s 循环），我们进战场只有 BGM。静音的战场比"少了技能音"更空。
5. **BGM 场景只有 2 个**：我们只有"大地图 06"和"战斗地形 3 首"，缺菜单/内政/结局。其中 **17（大地图）+ 03（菜单）** 两首就能覆盖玩家 80% 的非战斗时间，成本 2 首 ≈ 2.6 MB（@64k）。

## 3. R223 两个实机 bug（本报告重点）

**Bug A 主将变守方**：两层原因。① 历史层：`DeployRoot.start()` 曾恒取 `data.scenarios[0]`，于是《讨伐董卓》读到剧本 0 的平原守将（張角/廖化/管輅/裴元紹/蔣義渠/杜遠 —— STR+INT 降序 151/144/128/113/113/101 与实机截图完全吻合）；② 残留层：即使剧本号对了，我方候选池仍用 `generals.json` 静态 `CITY` + `save.owned` 兜底，且 `majorOf()` 读**目标城**（樂陵是关卡、`major:''`）⇒ 主将退化成统智最高的關羽。
修法（`DeployRoot.ts`）：我方池改 `O.officerNamesOfCity(save, this.home, ctx)`（出发城存档人事），太守优先取 `home`；敌方守军/敌情仍取 `targetCity`。

**Bug B 出征只带 5 兵**：`generals.json` 401 条**没有 `level` 字段** ⇒ `generalLevel()` 恒 1 ⇒ `troopCapOf(1)=min(1×5,100)=5`。修法（`CampaignRoot.ts`）：`armyGeneralLevel` 改 `scenarioLevelOf(name, max(1, own))`（剧本起始等级），`dispatchArmyTo` 改 `taken = min(cap, 城兵)`；244 兵 + 劉備 Lv2 ⇒ **10 兵**，城兵不足则全带，0 兵才拒绝。

## 6. 坑（本轮新增）

1. **`tsc -p cocos` 绿 ≠ web `tsc --noEmit` 绿**：测试静态 import Cocos 源码会把 `game/cocos/**` 拉进 web 程序，缺 `"type":"module"` 就每行报 `TS1287`。修法：`game/cocos/package.json` 加 `"type":"module"`（Creator 不读）。
2. **`sync_core3.mjs` 的 `SKIP_FILES`（roster/field）造成假绿**：`--diff-only` 说「23/24 相同」但 roster 根本没参与同步。F-01 的根因就是这个。
3. `tsc -p cocos/tsconfig.json`（Creator 生成）有 465 条既有错误，**门禁只认 `cocos/tsconfig.check.json`**。
4. Cocos 城状态分散在 `sanguo_city_v1`（CityPanel）+ `sanguo_items_v1`（物品）+ GameState，月推进要在 CityPanel 开过页后才有数据源（已用 `CityMonthBridge` 桥接）。
5. 模拟器取图：`adb shell screencap -p /sdcard/x.png` + `adb pull`；`exec-out >` 会被 PowerShell 写坏 PNG。
6. 模拟器点击坐标要按 1456×2560 换算（截图预览 963 宽 → ×1.512），底部按钮 y≈2340 才稳。

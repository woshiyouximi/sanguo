## 6. 坑（本轮新增）

1. **验证浏览器必须 `close` + `reap`**：`Browser.close` 偶尔只关标签页不退进程，累积会把 CPU 打满（用户报的「程序泄露」）。`cdpweb.mjs` 的 `close()` 现在按 profile 名 Stop-Process 兜底，另有 `reap.mjs --kill --match=` 扫尾。
2. **pwsh 内联 `node -e "…中文…"` 会被 PowerShell 拆坏**（`ParserError`）——含中文/引号的脚本一律先 `write` 成 `.mjs` 再跑。
3. **不要用 `h.find(node, 'HudFace')` 找节点**：`steps_hud_dump.mjs` 的 `find` 匹配的是**组件类名**，找节点要自己 `walk` 比 `n.name`。
4. **`window.__sanguo.world` 不存在**，真实路径是 `window.__sanguo.state.world`（`?rel=1` 或 UA `SanguoShell` 下整个 `__sanguo` 不挂）。
5. **镜头与叫阵必须同源**：`beginTaunt` 先把 `camX` 设到说话方，`camera()` 旧锚点 48.40 会在恢复帧把它拖回去——两处都改成「主将 − 2」后才稳定。
6. **`rand() & 1` 不是 50%**：原作 rotate 两段移位相加在轮转量 0 时退化成 `2x`，实测 48.3–48.4%；任何「均匀随机」假设都会让逐帧对拍错位。
7. **CDP 打开的窗口若在后台，rAF 会被节流**：叫阵只推进到第一句就停住，看起来像「第二句不播」的 bug。跑带时间推进的验收前先 `Page.bringToFront`（`steps_e2e.mjs` 已加）。

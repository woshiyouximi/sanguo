**「全包、资源在包内且会加载」三份证据**：

1. `assets/src/settings.json`：`remoteBundles: []`、`projectBundles: ["internal","main","res"]`、`preloadBundles: [{bundle:"main"}]`、`server: ""`、`launchScene: db://assets/scene/Boot.scene`。

## 7. 坑

1. `tools\build_native.ps1` 头上有 `#requires -Version 7.0`，用 `powershell`（5.1）跑会直接拒；必须 `pwsh` 或 `& .\tools\build_native.ps1`。
2. `edit` 写 `.ps1` **会掉 UTF-8 BOM**，`powershell -File` 按 GBK 读整篇 mojibake（`Unexpected token`）。每次改完补 BOM + `[Parser]::ParseFile` 验 `parseErrors=0`。本轮又踩两次。
3. `Copy-Item -Destination` 目标目录不存在时，复制文件夹会报 `Container cannot be copied onto existing leaf item`；先 `New-Item -ItemType Directory -Force`。
4. Cocos CLI 只认 `--build "configPath=..."`，`packageName=` 之类参数进不去；**退出码 34/36 是正常的**，判据是日志 `build Task (android) Finished`。
5. `gradlew` 连 services.gradle.org 会超时，`repo1.maven.org` 不通 —— 用本机 gradle 缓存 + aliyun 镜像。
6. 包名里不能有 Java 关键字：`com.sanguo.native` 非法 → `com.sanguo.sango2`。
7. Cocos 3.8 的资源扩展名在**每资源 import json 的 `fmt` 下标**里（png=0/webp=4），不在 `config.*.json`。
8. 256 色量化对已是 8bit 调色板的 png 零收益；`convert('RGB')` 会把 alpha 丢光。
9. 改完 `game/src/**` 必须重跑 `tsc -p tsconfig.build.json`，否则保真网报 `env.dist.stale got=2 want=0`。
10. 版本号不在 Cocos 构建配置里，在生成的 `native\engine\android\app\build.gradle`。

## 1. 数据实况（用 node 校过，别假设）

`wises.json` 67 条，真实字段是 `{SEQUENCE, Execute, WiseLevel, NAME, ATTRIB, Level, ACTIVE}`——**没有 `Rate`**（任务书里那条是误写）。
- `WiseLevel` = 档次：同名技 3 条（1/2/3 档），独有技为 0；本作按档给固定强度，`Rate` 不存在也无从取值。
- `ATTRIB` 是数字：0 普通数值、1 战前选择（後選出陣 3 / 勸降 32）、2 化解計策 24、3 站位类（逼近 23 / 包圍 26 / 偷襲 30）。
- `ACTIVE` 是 1/2/4/8 的分组位，不是强度；`Execute` 是同档执行代码号。
- 武将的 `WISESKILL` 是**逐级学习表**：`["1, 8", "6, 16"]` = 1 级学 #8、6 级学 #16；同名技会在 3 个不同等级各出现一次（不同档）。65 个武将都是这样。

## 3. 给 battle.ts 的契约：`world.wises`

`wises.ts` 用类型断言挂了一个侧表，不改 `World` 声明（避免与正在改 battle.ts 的 agent 撞车）：

```ts
world.wises = [{ side: 'A', kind: 'qi_regen', value: 25, seq: 9 }, ...]
// kind: 'qi_regen'（每 tick 气力回复倍率 %）| 'qi_cost'（技能耗气减免 %）
//      | 'troop_atk'（士兵攻击力 %）| 'exp_bonus'（战后经验 %）
```

消费点（`battle.ts` 里 4 处 `if`，参考 `docs/04b_战斗系统.md` §4.3 的位掩码+百分比做法）：
1. `tickSkills()`：`general.qi += QI_REGEN_PER_TICK * (1 + wiseBonus(world, side, 'qi_regen')/100)`，仍夹 `QI_MAX`。
2. `cast()` 扣气力：`qiCostOf(...) * (1 - wiseBonus(world, side, 'qi_cost')/100)`。
3. 士兵命中/伤害：`hitChance` 或伤害式里乘 `(1 + wiseBonus(world, side, 'troop_atk')/100)`。
4. `settle()`：`expGain *= 1 + wiseBonus(world, side, 'exp_bonus')/100`（与 `post.expBonus` 叠加）。

`wiseBonus(world, side, kind)` 直接读 `world.wises`，同通道可叠加（測試钉了 16+17 = +18）。

## 8. 消费点已落地（battle.ts，4/4）

四处都在 `F:\sanguo\game\src\core\battle.ts`，注释里标了 `（依据：docs/04b §… / project/26 §3）`：

| 通道 | 落点 | 式子 | 测试 |
|---|---|---|---|
| `qi_regen` | `tickSkills()` 每侧回气 | `qi = min(QI_MAX, qi + round(QI_REGEN_PER_TICK*(1+bonus/100)))` | 集氣 +25% → 1000 打成 1250 |
| `qi_cost` | `cast()` 扣气 | `qi = round(qiCostOf(seq) * qiCostMul(world,side))`，`qiCostMul = max(0.1, 1+bonus/100)` | 保留氣力 −20% → 系数 0.8 |
| `troop_atk` | `powerOf()` 战力 | `round((150+兵种+地形+阵形+士气) * (1+bonus/100))` | +8% → `round(p0*1.08)`，无军师技时逐位不变 |
| `exp_bonus` | `settle()` 经验 | `expGain = round(expBase*(1+bonus/100))`，其后照旧 `+post.expBonus` | +15% → `round(plain*1.15)` |

**符号坑（重要）**：`SPECS` 里 `qi_cost` 存的是**负数**（`8/36/56 = −20/−30/−45`，note 写"氣力消耗 −20%"），所以系数是 `1 + bonus/100`（= 0.8/0.7/0.55），**不是** §3 写的 `1 − bonus/100`（那套写法假设 bonus 为正）。另外 `troop_atk` 按 §2 的口径是**百分比**（+8/14/20 或 +10/18/26），不是加绝对值；无军师技时四个系数都是 1/0，战力与经验逐位等于旧值，所以 `battle.test.ts` 里原先的地形/结算断言不用改。

测试：`game/tests/smartscript.session.test.ts` 的「军师技 4 个消费点」一条覆盖四通道；`game/tests/wises.test.ts` 的 25 条仍只测 `world.wises` 数值与 `applyWise` 返回值（不 step），互不影响。

### 4.3 `trunc(str*4/10)` 的取整點 [确认]

原作 `0x427947`：`mov eax,[執行武將+0x34]; shl eax,2; idiv 0xa` —— **先乘 4 再整除 10**（向零截斷），
然後才 `+ rand()%12`，最後才做太守縮放。本作原本用浮點 `str * DEV_FORMULA.PER_STR`（0.4），
改成整數式：

```js
// game/web/city_model.js:903
const defBase = randBelow(DEV.DEF) + Math.trunc((str * 4) / 10);
```

差分量測（F3，STR 999，`rng 0.99` → `rand()%12 = 11`）：`trunc(999×4/10) = 399`，`defBase = 410`，
縮放後 **`def = 431`**；四捨五入會是 400 → 411 → **432**。`DEV_FORMULA.PER_STR` 仍保留 `0.4`
（文件值，`rows85.test.ts` 釘住），只是不再拿它做浮點乘法。
另外實探：對 0..2,000,000 的整數 STR，`trunc(s*0.4)` 與 `trunc((s*4)/10)` **零差異**——
所以本條的差分刻意用「截斷 vs 四捨五入」，不謊稱浮點乘法本身會偏。

# 218 · 原作时间流反汇编（内政終了 ≠ 跑一年）

**结论**：原作大地图的时间是**每帧自动 −1 的计数器** `T=[0x4C30E0]`，一年 3600 tick、一月 300 tick、一天 10 tick；
`T==0` 时**自动**切进内政场景（并在进入时 `year+1`）；「內政終了」按钮只做一件事——**把 T 重置为 3600 并切回大地图**。
原作**没有**「月份推进函数」，也**没有**一次跑完 12 个月的代码：月份只是从 T 现算的显示值
（`month=(3600−T)/300+1`、`day=((3600−T)%300)/10+1`）。

我们此前 `CampaignRoot.endInterior()` 与 web `campaign.html` 的 `endMonth()` 都是「按钮回调里同步跑 12 个月」，
所以点一次内政終了＝过一年，且兵团在瞬间位移——与原作不符。

## 1. 证据（`llvm-objdump -d` 逐条核对 `work/units_per_side/Sango2.exe`）

## 2. 我们改成什么样（Cocos 为基准）

`game/cocos/assets/scripts/CampaignRoot.ts`：

- 字段 `clockT=3600 / clockAcc / clockSpeed=1 / clockPaused`（注释带证据地址）。
- `update(dt)`：60Hz 固定步长累积 → `stepClock(clockSpeed)`；`clockRunning()` = 未暂停 && 城内页未开 && 无 `Scrim_*` 遮罩。
- `stepClock(n)`：`T = max(0, T−n)`；按 `floor((3600−T)/300)` 跨月逐次 `monthTick()`；`T<=0` → `enterInterior()`。
- `monthTick()`（原 `endInterior()` 的循环体）：`GameState.advanceMonth` → `advanceArmiesMonth()` → `runMapAi()` → 战报/刷新；遇遭遇战则暂停时钟。
- `enterInterior()`：`clockPaused=true`、`T=0`、写战报、开城内页。
- `endInterior()`：**只** `clockPaused=false; T=3600; clockAcc=0` + 提示「一年 ≈ 60 秒，一月 ≈ 5 秒」。
- 按钮语义：时钟在走时右下按钮显示「時 間 流 動」并忽略点击（原作这颗按钮只属于内政场景）；停着才显示「內 政 終 了」。

**节奏**：`clockSpeed=1`（60Hz 下每秒 60 tick）⇒ 1 月 ≈ 5 秒、1 年 ≈ 60 秒。原作不限帧，
「一年多少秒」依当年机器而定，所以我们取一个可玩的固定值，并把速度做成变量。

## 5. 坑

1. `(Get-Content) -replace … | Set-Content -NoNewline` 会把 5000 行文件粘成一行（tsc 仍绿、文本断言全红）；改大文件只用 python + `newline='\n'`。
2. `cityPanel.isOpen()` 是**方法**，写成属性会静默为 `undefined`（时钟永不暂停）。
3. 测试断言方法体时别依赖 `fnBody(src,'update')` 这种只认无参签名的辅助；`update(dt: number)` 会取到空串。
4. 布局常量变了（出征页右上勾选框）要同步改断言里的 `GEN_W - 16 → GEN_W - 34`。

## 3. 叠层结构（`style.css` §23）

```css
.screen{isolation:isolate}                  /* 伪元素关在这一层里 */
.screen::before{ content:""; position:absolute; inset:0; z-index:-1; pointer-events:none;
  background-image: <压暗渐变>, <底图>, <纯渐变兜底>; background-size:cover; }
```
- **兜底层**：`background-image` 里每组最后垫一条 `linear-gradient(160deg,…)`。图 404 时浏览器直接跳过该层不绘制，
  自然露出下面的渐变/屏底色 —— 不需要 JS 探测，也不会白屏。
- 选屏靠 `data-scr`：`app.js render()` 里 `scr.setAttribute('data-scr', id)`（新增 1 行），
  九屏的屏根都是裸 `<div class="screen">`，不逐屏改 DOM。
- 压暗渐变按屏调，范围 `.44–.74 → .68–.90`（下表）；分区卡片统一 `rgba(16,20,26,.72)`，
  1px 描边沿用 `.card9::before` 的内描边（不加 border，避免 1px 挤动布局）。

## 4. M1 为什么要画进 canvas（不能用 CSS background）

`m1.js` 的 `proj(x,y)=[ox+(x-MAP.x0)*sc, oy+(y-MAP.y0)*sc]`，`sc/ox/oy` 随 `zoom/panX/panY` 变。
底图必须吃同一套变换，否则一放大城点就漂到海里。做法：

```js
var IMG={w:1280,h:960,el:null,ok:false};          // 缺图时 ok 保持 false，draw() 退回宣纸底纹
ctx.drawImage(IMG.el, ox-MAP.x0*sc, oy-MAP.y0*sc, IMG.el.width*sc, IMG.el.height*sc);
ctx.fillStyle='rgba(8,11,16,.40)'; ctx.fillRect(0,0,w,h);   // 暗幕
// + createRadialGradient 暗角 .60
```
画**整幅**而不是只裁 `MAP` 窗口（`x 88–1138 / y 84–860`）：只裁窗口会把台湾岛切掉，夷州那颗点就悬在海上。
实测 60 城 + 116 条路按 1:1 叠在 CHINAMAP 上 **0 城落海**（`work/map_align_check.png`）。

## 6. 与任务书不符的三处实测（按实际素材做）

1. `SHAPE\BG\` **没有 `FLOOR*` 512×512 平铺材质**：该目录是 `BG00–11`(730×96) / `MG00–11`(880×96) / `FG00–11`(1000×96)
   三层**视差横条**（天/山/城墙），原作战场靠这三条横向滚动，不是平铺。B1 因此改用 AI 战场图。
2. `TITLEBG.png` 是 **640×480 / 303,735 B**，不是 619 KB 整屏；竖屏下不可能整张铺满，已改 AI 重绘同构图。
3. `serve.mjs` 的站根是 `F:\sanguo`，正确地址是 `/proto/ui/index.html?s=<id>`（任务书里 `/ui/index.html` 会 404）。

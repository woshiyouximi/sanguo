## 0. 一句话

`釋 放` = 原作 `0x491DF4` / `0x44EDB4`：只把 `status` 写成 **2**（AI 侧同一档的文案是
`0x481214 "%s將軍安全歸來!!"`），而 `0x40EF9A` 的分派 switch **对 case 2 什么都不做** ——
即"放他回原势力"，既不进我方名单、也不进斩首池。本作把它落成
`_moved[name]='釋放'` 哨兵 + `save.released` 累加。

### `game/data/generals.json` 的 `Status` 不是这套状态码

- 401 行；顶层 `Status` 取值 `未` 259 / `登` 79 / `野` 63，另有 `status_by_times`、`city_by_times`
  （五个剧本的逐剧本初值数组）。
- 例：呂布 `status_by_times ["登","登","未","未","未"]` / `city_by_times ["新野","洛陽","","",""]`；
  夏侯惇 `["野","登","登","登","登"]` / `["陳留","陳留","長安","江陵","新野"]`；華佗 全 `野`。
- 结论 `[确认]`：这是**剧本初始登场状态**（登 = 出仕、野 = 在野、未 = 未登场），与战斗内的
  `status` 码不是一套。释放写 `status=2` 只表示"这一仗放他回去"，**不会把 `登` 改成 `野`**、
  也不会把他从原势力的守将表里删掉。

## 2. 「释放后武将去哪」的最终口径

**最终口径**：回**原势力**（`+0x10` 势力 / `+0xCB` 君主 / `+0xD7` 所在城指针全部原样，不转在野、
不掉原城归属）；不进我方任何城的名单、不进斩首池、不写 `陣亡`、不复活忠诚惩罚。他下次照旧按
`garrison.json` 守城 —— 还能再被俘、还能再被招降。

四档决策的落库对比（`core/roster.ts:applySurrender`）：

| 决策 | 名单 | `_moved` | 存档键 | 可再遇 |
|---|---|---|---|---|
| `recruit`（且 `recruitable`） | 进 `roster[home]` | 清哨兵（若曾是 `釋放`） | 清 `captured`/`executed` | 已是我方 |
| `kill` | 从所有城摘除 | `陣亡` | 清 `captured`/`executed` | 否（永不复活） |
| `escape` / 君主 | 不动 | 不动 | 清 `captured`/`executed` | 是 |
| **`release`（本轮）** | **从所有城摘除（本来就不在）** | **`釋放`** | **清 `captured`/`executed` + 累加 `save.released`** | **是** |

### 为什么还要在 `_moved` 打哨兵（本作表示层，不是原作字段）

本作 `city_model.rosterOf()` 是用 `generals.json` 的**静态** `city_by_times` 反推"这座城有谁"。
城一旦易主，这座城的原守将立刻被算成"我方"（`project/92 §10.1` 已记的表示缺陷）。要兑现
"不进我方名单"（否则 `04_after_release.png` 那一屏里他还挂在陳留名下），只能借 `_moved` 这唯一
真源打哨兵：`_moved[name]='釋放'`、静态数据一字不改。哨兵只表达"不在我方任何城名单"，并且
**重新招降时会被摘掉**（`applyCapturesToRoster` 里 `delete moved[name]`），否则招回来的将
`rosterOf()` 仍然不认。

### `[推测]` 三处（证据不足，已按最能自洽的一种落地）

1. **`[推测]` 释放后具体"回哪座城"**：`docs/04b2:599 §8 未解 3` 连"招降后所在城由谁重写"都没
   定位；释放路径连 `0x406C5C` 都不调，说明 `+0xD7` 保持原值。若原城已易主，原作是否另派一城
   无法从现有证据判定。本作口径取"原城指针不动"，于是该城归我时他也不会出现在我方名单（哨兵）。
2. **`[推测]` AI 侧 50% 放回是否与玩家三键共用同一条收尾**：`0x40452E` 写 `status=2` 后走
   `0x40EF9A` 的 case 2 是 `[推测]`（只定位到写码与文案，没定位到调用点）；status=2 与
   `"%s將軍安全歸來!!"` 的绑定是 `[确认]`。
3. **`[推测]` `save.released` 是本作新增存档键**（不是原作字段），只供战报/后查；`saves.js` 对
   未知键原样保留（本轮没动 `saves.js`，另一 agent 在改）。

## 4. 不变量（测试逐条钉住）

1. **不进我方**：`releaseFromPools()` 从所有城数组 `splice` 同名，并打 `_moved='釋放'`；表现层
   `CM.rosterOf()` 因此不再列他（`:355` 用例前后各查一次名单）。
2. **不进斩首池**：`save.executed` 里他被清掉；`_moved` 不是 `陣亡` → 下次再被俘照出卡（`:441`）。
3. **存档**：`save.released` 保序去重累加（`:425` 两仗各一个 → `['A','B']`；同批重放不增长）。
   已实测存档往返：`upgradeSnapshot()` / `prepareSnapshot()` 走 `deepClone + ensureSnapshotShape`
   （`saves.js:234`「不改已有值、**不删未知键**」），喂 `{released:['夏侯惇','華佗'], roster:{_moved:{夏侯惇:'釋放'}}}`
   进 `prepareSnapshot(raw, [])` 原样出来 —— 战报键不会被存档层丢掉。
4. **幂等**：同一批卡 + 同一批决策再落一次库，`released` 仍列出他、`save.released` 不变、
   `captured`/`executed` 仍空、名单不动。
5. **君主例外**：`isKing` 先于一切 → 即使决策写 `'release'` 也走 `escaped`，不写 `save.released`、
   不动名单（`:394`）。
6. **斩首优先**：`releaseFromPools()` 第 195 行 `if (moved[name] === DEAD) continue;`（`:449`）。
7. **释放后可再招**：`applyCapturesToRoster()` 摘哨兵后 `rosterOf()` 又列他（`:355`）。
8. **档位无关**：`release` 在 `recruitable === false` 的卡上照样可点、照样生效（`:381`），对应原作
   三键并列没有硬门。

本机**没有 `pwsh`**、且执行策略禁止 `& xxx.ps1`（`PSSecurityException: 在此系统上禁止运行脚本`），
所以 Start-Process 必须内联；`--window-size` 先赋变量再入数组（每元素一个参数，否则 msedge 报
`Multiple targets are not supported in headless mode`）：

```powershell
$edge='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$prof=Join-Path $env:TEMP ('edge-sur-'+[guid]::NewGuid().ToString('N').Substring(0,8))
$W=750; $H=1334
$argv=@('--headless=new','--remote-debugging-port=9435',"--user-data-dir=$prof","--window-size=$W,$H",
        '--hide-scrollbars','--no-first-run','--no-default-browser-check','--disable-extensions',
        '--enable-unsafe-swiftshader','about:blank')
$p=Start-Process -FilePath $edge -ArgumentList $argv -PassThru
Start-Sleep -Milliseconds 1600
node F:\sanguo\work\surrender\_cdp.mjs "--port=9435" "--url=<上面那条 URL>" `
  "--out=F:\sanguo\work\surrender\04_after_release.png" "--w=750" "--h=1334" "--wait=14000" `
  "--js=F:\sanguo\work\surrender\_probe2.js"
Stop-Process -Id $p.Id -Force
Get-CimInstance Win32_Process -Filter "Name='msedge.exe'" |
  Where-Object { $_.CommandLine -like "*$prof*" } | Stop-Process -Force
Remove-Item -Recurse -Force $prof
```

静态服务器沿用上一轮的 `node web/serve.mjs 5173`（cwd `F:\sanguo\game`），`dist/` 由它直接服务，
所以改 `src/core` 后必须 `tsc -p tsconfig.build.json` 重建。每次截图都用**全新** `--user-data-dir`，
否则 `added`/`released` 幂等让标注消失。

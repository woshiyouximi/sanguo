# R244 打下的城不再冒前主人的將（4.15）

製作人七條實機回報（原文摘要）：

1. 佔樂陵（沒有武將的城），劉備關羽張飛 3 個人去的；
2. 到達觸發戰鬥，劉備先上、輸了，**沒觸發輪戰**，點擊後直接回大地圖；
3. 但顯示樂陵**我方已佔領**；
4. 之後有 AI 隊伍來攻打；
5. 我觸發守城戰，守城隊伍卻**和我無關，是袁紹的**；
6. 袁紹的隊伍我只能選 **2 人**出戰；
7. 第一個袁紹撤離後觸發輪戰，**第二個上場的卻是關羽**。

## 根因（三條，互相獨立）

| # | 位置 | 舊行為 | 後果 |
|---|---|---|---|
| a | `OfficersOfCity.ownedCityNames()` | `roster[城]` 為空就回落**劇本表**駐將 | 樂陵是袁紹的劇本城 ⇒ 我方城的守將是袁紹的人（⑤⑥） |
| b | `GameState.recordBattleResult()` | 守城戰的 `armyId` 指向**來犯敵軍**，卻照樣 `absorbArmyPeople()` | 敵將被寫進我方城名冊（⑤⑦ 名單混編） |
| c | `BattleRoot` 結算 | 攻城戰兵團抵達時已 `removeArmy()`，`armyId` 找不到兵團 | 這批將打完仗人間蒸發（②「沒輪戰就沒人了」） |

另外 `save.cities[城].officers`（`garrison.json` 的舊主守將快照）與 `roster[城]`（AI 月結寫進來的舊主名單）在佔城時都沒清。

## 修法

1. **接管標記**：`CampaignSave` 新增 `takenOver?: Record<string, number>`（城名 → 接管月份）；
   `GameState.markCityTaken()` 寫月份、清 `cities[城].officers`、刪 `roster[城]`（我們的將由隨後的
   `absorbArmyPeople()` 補進來，順序不能反）。`occupyCity()` 與 `recordBattleResult(won)` 都調它。
2. **不再回落劇本表**：`OfficersOfCity.ownedCityNames()` 在 `roster` 為空時先看 `takenOver`
   （`takenOverOf()`），有記錄直接 `return []`。新局起始城沒有標記 ⇒ 仍走劇本表保底
   （`initCampaign()` 不寫 `roster`，那條保底不能刪）。
3. **只還原我方的人**：`recordBattleResult()` 的 absorb 加 `fought.side === 'A'` 判斷。
4. **攻城戰打完把將還回城**：`GameState.returnGeneralsToCity(city, names)`；
   `BattleRoot` 結算時取 `launch.rosterA` 減去陣亡者，贏了寫回打下的城、輸了寫回 `launch.home`。
5. **守城戰敵方名冊＝來犯兵團**：`DeployRoot.enemyRoster()` 先按 `this.defenseArmyId`
   從 `save.armies` 取 `general + officers`，找不到才回落 `intel`；攻城/守城兩條起戰路徑都改用它。
6. **取證日誌**：`recordBattleResult()` 印 `[R244] battle result { city, winner, defend, armyId, owned }`
   —— 製作人說「打輸了城卻變我的」，這條日誌能直接對出是參數還是別的路徑（`adb logcat -s Cocos`）。

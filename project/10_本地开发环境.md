## 4. 工程约定

1. **逻辑与表现分离**：`game/src/core/` 不 import 任何渲染/引擎 API；视图层（`src/view/`、Cocos 的 `cc`）只消费 `World` 的快照。
2. **固定步长**：逻辑 30 Hz（`TICK_HZ = 30`），渲染帧率无关；所有"秒"都要能从 tick 数换算。
3. **同 seed 可复现**：`createWorld({ seed })` + `mulberry32`，测试与对拍都靠它。
4. **数据只读**：`data/*.json` 是构建产物，改动请改 `tools/import_legacy.py` 再重导。
5. **中文控制台**：每个 pwsh 会话先执行
   `$env:PYTHONIOENCODING='utf-8'; [Console]::OutputEncoding=[System.Text.Encoding]::UTF8`，否则 Python 输出中文全乱码。
6. **路径有空格/中文**：PowerShell 里一律 `-LiteralPath` 或双引号包裹。

## 5. ComfyUI（本机）怎么用

- 工作流已固化在 `F:\sanguo\cloud\run_batch.py`（t2i 与 i2v 两条分支），**不要手搓节点图**。
- 本机跑一条 i2v：
  ```powershell
  Set-Location F:\sanguo\cloud
  $env:COMFY_OUTPUT='F:\AI\ComfyUI\output'
  & $py run_batch.py --jobs jobs_local_i2v.csv --out F:\sanguo\project\art_ref\anim_local --filter kind=i2v
  ```
- 首帧图必须先放进 `F:\AI\ComfyUI\input\`（`LoadImage` 只认 input 目录）。
- 已知坑：文本编码器必须用 `qwen3vl_8b_int8_convrot`（Qwen-Image 要 hidden 4096，7B 的 3584 会报 `normalized_shape`）；i2v 的 `SaveImage` 输出的是**逐帧 PNG**，不是视频。

## 7. 常见故障

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `npm : 无法加载文件 …npm.ps1` | 执行策略 | 用 `npm.cmd`，或 `Set-ExecutionPolicy -Scope Process Bypass` |
| Python 输出 `????` | 控制台编码 | 见 §4.5 |
| `node --test` 报 `Unknown file extension ".ts"` | Node < 22.6 | 本机是 24，正常应能跑；若换了机器需 `--experimental-strip-types` |
| ComfyUI 报 `normalized_shape` | 文本编码器选错 | 换 `qwen3vl_8b_int8_convrot` + `type=qwen_image` |
| 云上 `无输出文件` | `COMFY_OUTPUT` 相对路径 | 显式 `COMFY_OUTPUT=/workspace/ComfyUI/output` |
| 云上回传中文名乱码 | Windows tar 解压 | 用 Python `tarfile` 解（UTF-8） |

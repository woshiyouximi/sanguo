## 二、這輪做了什麼

### 1. 新模組 `game/cocos/assets/scripts/RosterLedger.ts`
純邏輯、不 import `cc`（所以能在 Node 測試直接跑）。定義一名武將**恰好**一個位置：
`city:<城>` / `army:<id>` / `siege:<城>` / `gone`（`generalStatus` = 死/俘）。

- `locate(save, name)`：這名將現在在哪。
- `audit(save)`：四條不變量（重疊 `dupes`、幽靈 `ghosts`、復活 `revived`、失蹤 `missing`）。
- `seedOwnedCity(save, city, names)`：開局播種，寫一次；`takenOver` 的城不播。
- `handoffCapture(save, city, survivors)`：攻城交接——清舊主名冊/守將快照、記接管月份、寫存活者（同一名字從別城摘掉）。
- `resolvePendingSieges(save, { minWait })`：月結兜底——敵軍抵達後每過一個月邊界 `siegeWait + 1`，滿 `minWait`（默認 2）按 `城兵 + 城防/8` 對 `來犯兵` 自動出結果：破城⇒城易手、守將 `俘`；守住⇒敵退、城兵減。

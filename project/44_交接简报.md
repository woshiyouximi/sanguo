## 5. 坑表（血泪，按严重度排）

1. **绝不要用 PowerShell 的 `Get-Content|Set-Content|>|Add-Content` 写含中文的源码**。已因此毁过 3 个文件（`tests\yearsettle_r7.test.ts`、`work\fidelity\gen_expect.mjs`、`game\src\core\battle.ts`+`layout.ts`）：PS 5.1 按 ANSI/CP936 读 UTF-8 → 文件变 `?` 或 U+FFFD，**不可反解**。写文件只用 `write`/`edit` 或 python 显式 `encoding='utf-8'`。
2. `.ps1` 必须带 UTF-8 BOM，否则 WinPS 5.1 按 ANSI 读会报满屏 `Unexpected token`；改完用 `[Parser]::ParseFile` 验 `parseErrors=0`。
3. **改 `game\src\**` 后必须 `tsc -p tsconfig.build.json`**，否则 web 跑的是旧 `game\dist`。
4. `-Mode preview -SkipWeb` **不重建** `game\cocos-build\web-mobile`（CDP 会看到旧包）；要重建就别带 `-SkipWeb`。
5. Cocos 页面在**后台不跑 rAF**：`getScene()` 为 null、`getTotalFrames()` 不涨、`loadScene` 报 1209。截图前必须 `Page.bringToFront` 并确认帧在涨。
6. 微信开发者工具 GUI：`ENOENT assets/res/index.*.js` 是编译缓存（用 `tools\make_test_build.ps1` 生成新目录再开）；`80051 ... exceed max limit 4MB` 是它把分包并进主包算（CLI 上传正常）。
7. **该 AppID 的包体上限是 20 MB**（不是文档写的 30 MB）：`-Audio embed` 出 23.07 MiB、CLI 照样报 `23388KB exceed max limit 20MB`；所以音频必须压到 32k mono（当前 6.01 MB）。
8. `game\web\index.html` 是**战斗预览页**（顶部兵种/阵形/種子工具条 + 開戰引导卡），发布形态绝不能当首屏；APK/微信入口都是 `campaign.html`。
9. 键盘六按钮**不能走 hitTest**（部队指令面板展开会盖住按钮），要按 `CMD6_BUTTONS` 表直接派发。
10. `createWorld` 的 `a:` 传字符串会整个替换默认对象导致 `str/int` undefined、hp 变 NaN，必须传 `{name,str,int,level}` 对象。
11. `work\cocos_sync\sync_core3.mjs` 的 `SKIP_FILES` 键是**相对 `game/src/core` 的文件名**（`'roster.ts'`，不是 `'core/roster.ts'`）。
12. 多 agent 并行时：**core 同步只由 lead 在收工后跑**；每个 agent 的写集互斥；不要让两个 agent 同时改 `battle.ts`。
13. **提交被拒 = 有文件被 CP936 写坏**：`.githooks/pre-commit` 用 `work\enc\scan_utf8.mjs` 扫 staged 的文本文件，命中 U+FFFD / 非法 UTF-8 直接中止提交。真物证（故意留的坏文件）先登进 `work\enc\allowlist.json` 再提交；`--no-verify` 只在完全知情时用。

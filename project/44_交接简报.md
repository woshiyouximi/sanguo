## 5. 坑表（血泪，按严重度排）

1. **绝不要用 PowerShell 的 `Get-Content|Set-Content|>|Add-Content` 写含中文的源码**。已因此毁过 3 个文件：PS 5.1 按 ANSI/CP936 读 UTF-8 → 文件变 `?` 或 U+FFFD，**不可反解**。写文件只用 `write`/`edit` 或 python 显式 `encoding='utf-8'`。
2. `.ps1` 必须带 UTF-8 BOM，否则 WinPS 5.1 按 ANSI 读会报满屏 `Unexpected token`；**`edit` 工具写 `.ps1` 会顺手把 BOM 去掉**（R212/R213 连踩三次）——每次 `edit` 后补：`$t=[IO.File]::ReadAllText($p,[Text.Encoding]::UTF8); [IO.File]::WriteAllText($p,$t,(New-Object Text.UTF8Encoding($true)))`，再用 `[Parser]::ParseFile` 验 `parseErrors=0`。
3. **改 `game\src\**` 后必须 `tsc -p tsconfig.build.json`**，否则 web 跑旧 `game\dist`、保真网报 `env.dist.stale got=2 want=0`。
4. `-Mode preview -SkipWeb` **不重建** `game\cocos-build\web-mobile`；要重建别带 `-SkipWeb`。
5. Cocos 页面在**后台不跑 rAF**：`getScene()` 为 null、帧数不涨、叫阵只播第一句。截图前必须 `Page.bringToFront` 并确认帧在涨。
6. 微信开发者工具 GUI：`ENOENT assets/res/index.*.js` 是编译缓存；`80051 ... exceed max limit 4MB` 是它把分包并进主包算（CLI 正常）。
7. **该 AppID 的包体上限是 20 MB**（不是文档写的 30 MB）；0.2.1 瘦身后磁盘 19.65 MiB 才过。
8. `game\web\index.html` 是**战斗预览页**，发布形态绝不能当首屏；APK/微信入口都是 `campaign.html`。
9. 键盘六按钮**不能走 hitTest**，要按 `CMD6_BUTTONS` 表直接派发。
10. `createWorld` 的 `a:` 传字符串会整个替换默认对象导致 `str/int` undefined、hp 变 NaN。
11. `work\cocos_sync\sync_core3.mjs` 的 `SKIP_FILES` 键是**相对 `game/src/core` 的文件名**。
12. 多 agent 并行：**core 同步只由 lead 收工后跑**；写集互斥；不要让两个 agent 同时改 `battle.ts`。
13. **提交被拒 = 有文件被 CP936 写坏**：`.githooks/pre-commit` 扫 staged 文本，命中 U+FFFD/非法 UTF-8 直接中止。物证先登 `work\enc\allowlist.json`。
14. **验证浏览器必须回收**：`Browser.close` 偶尔只关标签页不退进程，堆几十个 Edge 会把 CPU 打满。`cdpweb.mjs` 的 `close()` 已按 profile 名兜底；收工再 `reap.mjs --kill --match=<profile>`，回报写「遗留验证浏览器进程: 0」。
15. **pwsh 内联 `node -e "…中文…"` 会被 PowerShell 拆坏**，含中文/引号的脚本一律先 `write` 成 `.mjs` 再 `node` 跑。
16. **`h.find(node,'X')` 找的是组件类名**，不是节点名；`String.raw` 模板串里插注释**不能出现反引号**。
17. **`window.__sanguo.world` 不存在**，真实路径 `window.__sanguo.state.world`；`?rel=1` 或 UA `SanguoShell` 下整个 `__sanguo` 不挂。
18. **镜头与叫阵必须同源**：`beginTaunt` 先设 `camX` 到说话方，`camera()` 若还用旧锚点，恢复帧会把 56 拖回 48.4。

21. **叫阵台词框的 Label 与底板要一起开关**（Label 挂在 `consoleRoot`）。

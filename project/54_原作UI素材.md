## 2. 图元 → 用在哪 → slice → 为什么选它

> 每条都能在 `used_contact.png` 里看到"原图 / 实际效果"上下对照。

### 2.1 `frame_panel.png` ← `E1_D` 241×73 · **slice 8 / border 8px / 不 fill**

- **用在哪**
  - `deploy.html:39-42` `.sec::before` —— 主将 / 兵种 / 阵形 / 军师技 / 战前情报 / 兵力 **6 张卡片**的外框
  - `items.html:34-35` `.sec::before` —— 武将卡外框
  - `items.html:78-81` `.listcol`、`items.html:82-85` `.detcol` —— 两栏外框（这两个**直接画在盒子上**，因为 `.detcol` 自己是滚动容器，伪元素会跟着滚走）
- **为什么是它**：MENU 里 166 张能当"四边框"的只有几张，`E1_D` 是唯一同时满足「四边 alpha 全 255（真不透明）＋完全对称＋直角近方（圆角≈4）」的：结构是 1-2px 藏青外影 ＋ 4px 金带 ＋ 1px 暗红内影，和 `D0_B` 同一套笔法，最像原作窗口那圈线。
- **不 fill**：中间保持透明，卡片自己的 `rgba(16,20,26,.72)` 暗底照旧透出来 —— 这一条很关键，底图（`bg/policy`、`bg/env`）从卡片缝里露出来，但**正文永远落在暗底上**，可读性不掉。

### 2.2 `plate_btn.png` ← `D3_2H` 308×40 · **slice 16 / border 10px**

- **用在哪**：`deploy.html:115-117` `.btn`（返回 / 出征）、`items.html:152-154` `.btn`（装备 / 全部解锁/重选）
- **为什么是它**：`BUTTON01..10` 全系都烘了字（確定/取消/出征/離開/結束/最大攻擊…），一个都不能当通用按钮底（B1 已踩过）。剩下的空牌里，`D3_2G`(225×40)/`D3_2H`(308×40)/`D25`(183×40) 三张是**中空无字**的，`D3_2H` 宽度最大、四边最对称、带四角十字托，且 40px 高在 slice 16 下正好 1:1 不缩放（不糊）。
- **保留渐变底**：`border` 区域透明，`:btn` 原来的 `linear-gradient` 仍然从框里透出来当牌面色；`.btn.primary` 原来的 `border-color:var(--gold)` 被 border-image 覆盖，改写 `box-shadow:inset 0 0 0 2px rgba(216,179,106,.45),0 0 20px rgba(216,179,106,.10)` 保持"主按钮更亮"。

### 2.3 `plate_sq.png` ← `D0_B` 64×68 · **slice 12 / border 6px（小件）· 8px（大件）**

- **用在哪**

### 2.4 `plate_sel.png` ← `WAR08` 100×120 · **slice 12 / border 8px**

- **用在哪**：`items.html:107-109` `.irow.on::after` —— 列表里**当前选中的那件道具**
- **为什么是它**：原作打仗时框目标用的选择框（黄→红渐变＋四角钩）。列表里 77 行全是冷色，选中行是**全页唯一暖色强提示**，一眼就能找到；而且它自带"这是目标"的语义，比换一个金色描边更像原作。
- **零位移**：走 `position:absolute;inset:0` 的伪元素，切换选中不会让列表抖一下。

### 2.5 `bar_div.png` ← `WAR05` 111×12 · **背景拉伸 `100% × 8~11px`**

- **用在哪**
  - `deploy.html:23-25` header 下缘（11px）、`deploy.html:108-110` footer 上缘（11px）
  - `items.html:23-25` header、`items.html:147-149` footer（11px）
  - `items.html:88-89` `.gtabs` 页签条下缘（9px）
  - `items.html:100-101` `.ghead` 分组粘头顶条（8px，替掉原来那条 1px 灰线）

### 2.7 `force_01..13.png` ← `FORCE01..13` 16×16 · **19px / `pixelated`**

- **用在哪**：`deploy.html:76-90` `#troopgrid .it::before` —— 13 个兵种格左侧的**兵符单字图标**
- **顺序核对过**：13 张的汉字依次是 **朴 / 槍 / 刀 / 弓 / 鏈 / 飛 / 武 / 蠻 / 鐵 / 籐 / 黃 / 弩 / 女**，与 `TROOP_NAMES` 的 0..12（朴刀/长枪/大刀/弓箭/链锤/飞刀/武斗/蛮族/铁缒/藤甲/黄巾/弩兵/女兵）**严格一一对应**，也与页面里 `TROOP_BY_CHAR`（刀→2、槍→1、弓→3、鍊→4、飛→5、武→6、蠻→7、鐵→8、籐→9、賊→10、弩→11、女→12）吻合。

### 2.8 `assets/items/*.png`（**0 新增**）← `JEWEL/WEAPONA1 · HORSEHA · BOOK01 · JEWEL01` 56×56 · **16px / `pixelated`**

- **用在哪**：`items.html:55-60` `.slot[data-slot="weapon|horse|book|amulet"] .k::before` —— 四个装备槽的槽名小图
- **为什么直接引**：这 57 张原图**早就在** `game/web/assets/items/` 里了（页面上每件道具的图标就是它们），CSS 直接 `url("assets/items/WEAPONA1.png")` 即可，不新增文件。`data-slot` 由页面自己渲染（`items.html` 的 slot 模板里有 `data-slot="${slot}"`），不用改 JS。

**统一手法**：凡是"给已有元素加框"，一律 `position:absolute;inset:0;pointer-events:none` 的伪元素 + `border-image`，**不给元素本身加 border**。

## 5. ⚠️ 唯一的 JS 改动：修既有 bug（`items.html:310-312`）

```js
// 改前
return 'assets/items/' + encodeURIComponent(stem) + '.webp';
// 改后
```

- 事实：`game/web/assets/items/` 下 **57 张全是 `.png`**（抄的就是 `SHAPE/JEWEL` 原图），**一个 `.webp` 都没有**；`assets/hero/` 才是 400 张 `.webp`。所以改前 **77 件道具的列表小图 + 详情大图全部 404 裂图**（`items_before.png` 里能看到一片裂图图标）。

### 环境坑（留给下一个人）

1. 本机是 **Windows PowerShell 5.1**：`pwsh` 不存在、`.ps1` 被执行策略挡住 → 命令只能整段 inline 塞进一次 `pwsh` 工具调用。
2. **绝对不要** `Get-Content -Raw | Set-Content -Encoding UTF8` 改这些 html —— PS 5.1 会把无 BOM 的 UTF-8 当 GBK 读、再写回成乱码（我干过一次，从备份恢复的）。脚本改写一律用 python `io.open(..., encoding='utf-8', newline='')`，或者直接用编辑工具。
3. Edge 截图**必须** `Start-Process -FilePath $edge -ArgumentList $a -Wait -PassThru -NoNewWindow`；直接 `& $edge ...` 会 exit 0 但不出图。

### 2.1 新建 `game/web/era.js`（纯函数，无 DOM / fetch / import，Node 可直接 import）

文件头注释写死了**内部口径**：

```
内部仍然是两个整数，一个都没改：
  save.month = 绝对月序（1 起，真源）      year  = floor((month-1)/12)+1
  save.year  = 上面那个 year 的冗余镜像（ensureYear() 会按 month 补）
本档只做「第 N 年 → 公元 Y 年」的换算与文案，不写回存档，
也不改 monthLabel() 的「第X年Y月」口径（老存档/老测试/存档格式 v3 都靠它）。
```

导出（`era.js` 行号）：

| 名称 | 行 | 作用 |

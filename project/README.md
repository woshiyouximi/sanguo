## 已定决策（一句话版）

1. **范围**：v1 **只换皮**——系统、数值、流程、内容一个字不改，只替换 UI 与美术，并适配竖屏（用户 m01592）。
2. **引擎**：Cocos Creator 3.8 + TypeScript（微信官方内置适配；Godot 只有社区插件、WASM 包体不可控）。
3. **战斗**：忠于原作，**100 人实时兵战**；呈现**转 90°**（14 行车道上屏幕左右、两军上下对冲、我方在下），一屏 14 车道 × 12.6 行，镜头纵向跟随（`PROJECT_BRIEF §6.1`）。代价是单位动画要出**背视 + 正视两套**，用户已确认算在"换皮"里。
4. **美术**：新国风厚涂；**本地 Qwen-Image 2.1 出图 + Wan 图生视频转序列帧 + 人工精修**，均已跑通。
5. **内容全量**：5 剧本 / 60 城 / 116 路 / 400 将 / 13 兵种 / 9 阵形 / 110 武将技 / 67 军师技 / 77 物品 / 12 地形。
6. **美术是唯一瓶颈**：约 765 张静态 + 172 条视频 + 4,900 帧，**精修约 600 人日**（`06`）。

## 三个最容易踩的坑（给接手的人）

1. 原作 PAK 的索引项名字字段是 **40 字节不是 16**，头部计数**不可信**（写 16447 实际 11110）。
2. 原作所有 INI 是 **cp950（Big5）**，不是 GBK——按 GBK 读会乱码但不会报错，静默出错。
3. 判文件格式**不要按扩展名猜**：`.TEX` 其实是标准 TGA、`.SHP` 是自研行编码 16bit、`.MSK` 是带调色板的 PCX RLE。要看引擎怎么读（反汇编加载器）。

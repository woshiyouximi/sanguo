### 2.4 已知缺陷（**重要，務必看**）

`generals.json` **沒有等級欄位**（401 條全部沒有 `LEVEL`），`levelOf` 只能回退 **20 級**，
而 20 級 ⇒ `cavalryCapOf = 0` ⇒ **正常遊玩時騎兵永遠徵不到**，右邊滑杆一直是 disabled、顯示 `0/0`。

這不是邏輯寫錯，是**上游資料缺欄位**（04c §7-6「經驗→等級表」未定位）。
本作先前在別處也是用 20 當默認（`game/cocos/assets/scripts/DeployRoot.ts:462-466`、`?lv=`）。
截圖 `after_recruit.png` 就是用 `?lv=30` 讓騎兵上限變成 300 才拍的，**正式玩法請把這條當「等資料補等級」的 TODO**。

## 3. R10 自治（城市代行內政）

### 3.1 原作證據（04c §2.3）

- `0x42771A "沒有設定自治的城市!!%K%"`
- `0x427865 "執行城市自治完畢!!%K%"`
- `0x4278CE / 0x4278F5 "自治施行"`

三條字串都在**內政命令區**（`0x427701(402)` 這支函式，就在 `0x4276C5(60)` 之後、開發 `0x427A84` 之前）。
⇒ 原作是：先把城「設定自治」，再下一次「自治施行」，就對這些城**批量執行開發**並印完成串。
它不是 AI 專屬機制，是玩家的第九條命令。

### 3.2 本作

|---|---|
| `city_model.js:914` | `AUTONOMY = { CMD:'自治', TITLE:'自治施行', NO_CITY, DONE, ROW(city,pop,def) }`（三條字串照抄原作） |

### 3.3 三個 `[推測]`

1. **「每月結算自動代行」是我們加的**：原作要手動按「自治施行」；本作做成「下過一次令 → 之後每月結算自動跑」，同時保留抽屜裡的「立刻施行一次」。兩條路都走同一支 `runAutonomy`，數值行為一致。
2. **當前所在城不代行**（`{from}`）：城主在的城通常要玩家自己決定開發時機；原作沒有這條限制的證據。
3. **「沒有設定自治的城市!!」也算用掉本月令**：抽屜按確定一律 `afterCommand(true)`，與原作「下了一次命令」一致，但無運行驗證。

## 10. 給其他 agent 的接口說明

### 10.1 `campaign.html`（我沒改，建議加 2 行）

`advanceMonth()` 裡（`clearMonthLock` 附近）建議補：

```js
M.autonomyTick(save, scenario.cities, ctx);   // R10 每月自動代行 + R12 全城補預備兵
```

`autonomyTick` 是純函式、寫回 `save`，不碰 DOM、不 throw（`cityDefs` 傳 `undefined` 也行）。
如果只想補兵、不要自治：`for (const c of scenario.cities) M.refillPrep(save, c);`

### 10.2 `city.html` 的資料接口

- 讀寫存檔仍然只經過 `Saves.*` 與 `M.*`；新增的存檔欄位都在 `ensureExtras` / `ensureCityState` 裡補齊，**老檔直接能開**。
- `window.__city` 追加：`prep`（`prepStateOf`）、`caps`（`armCaps`）、`auto`（`autoCities`）、`hall`（`hallImageOf`）、`tick`（`autonomyTick` 結果）。

### 10.3 除錯參數（都會在頁面上留註釋，正式玩法不受影響）

| 參數 | 作用 |
|---|---|
| `?unlimited=1` | 不鎖月令（**不寫檔**，不是玩法） |
| `?sheet=recruit｜auto｜intel｜move｜appoint｜deploy` | 進頁即開抽屜（截圖用） |
| `?force=1` | `?city=` 允許選非我方城（只影響顯示，不改所有權） |
| `?fresh=1` | 不讀槽位、直接開新局（截圖／驗收用） |
| `?hall=1..6` | 強制殿內背景（同時換 palais） |
| `?lv=N` | 武將等級回退值（騎兵上限用） |
| `?gold=N`、`?do=a,b,c` | 舊有 |

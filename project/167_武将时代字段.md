## B. 取值器（两份 `unlock.ts` 完全一致）

`game/src/core/unlock.ts` 与 `game/cocos/assets/scripts/core/unlock.ts` 同一段插在
`formationIndexOf` 之后（两份行号相同：71 `EraField`、77 `EraFieldRow`、91
`ERA_SCENARIO_COUNT`、94 `eraIndex`、104 `eraFieldOf`、118 `toTokens`、126 `eraTokensOf`）：

```ts
export type EraField = 'BattleArray' | 'Force' | 'UseForce' | 'LoyalKing' | 'Weapon';

export interface EraFieldRow {           // General 结构可直接传入（字段全可选）
  BattleArray?: string[]; Force?: string[]; UseForce?: string[];
  LoyalKing?: string; Weapon?: string;
  BattleArray_by_times?: string[][]; Force_by_times?: string[][];
  UseForce_by_times?: string[][];
  LoyalKing_by_times?: string[]; Weapon_by_times?: string[];
}

export const ERA_SCENARIO_COUNT = 5;     // 下标 0..4，与 levels_by_scenario.json 同口径

export function eraFieldOf(
  row: EraFieldRow,
  field: EraField,
  scenarioIdx: number,
): string | string[] | undefined;        // 时代优先；越界/缺项回落单值；两边都无 → undefined

function eraTokensOf(row, field: 'BattleArray'|'Force'|'UseForce', idx): string[]; // 列表归一
```

语义：`*_by_times[scenarioIdx]` 存在（且不是 `null`/`undefined`）就返回它，否则回落单值
（= TIMES1）。`""` 是合法的时代值（无君主），**不会**被当成缺项。`scenarioIdx` 非有限数
按 0，小数取 `Math.trunc`，越界不抛。签名比任务书多一个 `| undefined`（两边都没有时），
这是为了让 `toTokens` 能安全兜底，调用方仍按类型收窄即可。

接入点（两份都改了，均新增可选第二参 `scenarioIdx = 0`，旧单参调用行为 = TIMES1 不变）：

| 函数 | 行（两份） | 读取字段 |
|---|---|---|
| `troopsOf(general, scenarioIdx = 0)` | 131 | `UseForce` → 时代 |
| `allTroopsOf(general, scenarioIdx = 0)` | 136 | `Force` → 时代 |
| `formationsOf(general, scenarioIdx = 0)` | 141 | `BattleArray` → 时代 |
| `defaultTroopOf(general, scenarioIdx = 0)` | 146 | `UseForce` → 时代，退 `Force` → 时代 |
| `defaultFormationOf(general, scenarioIdx = 0)` | 161 | `UseBattleArray`（单值，原作 5 剧本不变）→ 退 `BattleArray` → 时代 |

`LoyalKing` / `Weapon` 本文件没有消费方（君主/武器在面板侧），给读取方统一入口
`eraFieldOf(g, 'LoyalKing', SCEN_IDX)` / `eraFieldOf(g, 'Weapon', SCEN_IDX)`。

兼容性：`game/src/types.ts` 的 `General` **没有改**（不加 `*_by_times`，避免动别的读取方）；
`EraFieldRow` 结构上兼容 `General`，所以 `troopsOf(g as General, idx)` 直接可传。
cocos 侧仍是 `Array.from(out)` / 局部变量 for-of 写法，没引入 spread-of-Set（Creator Babel loose 会编坏）。

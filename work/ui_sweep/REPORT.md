## 5. 結論

### 5.1 這套包在真機上的判斷：**不能玩（2.8）→ 勉強能玩但兩個必踩的 P0（2.9）**
- **2.8**：面板打開後全局輸入停擺（城池一覽/勢力圖/存檔位/名冊/物品 全部點不動），且穿透到地圖誤切面板 → 屬於「打開面板就死」的 P0，不能玩。
- **2.9**（hitfix 座標/Scrim 修復版）：標題→劇本→君主→大地圖→內政→出征→戰鬥 全鏈路都能到達，面板都能開關，內政 3 條命令數據閉環正確；但：
  1. **出征確認必崩**（穿透到內政終了 → mergeSave null.slice → 全局輸入死）——這是**主線流程的必經步驟**；
  2. **戰鬥點技能格必崩**（magic program toLowerCase → 戰鬥卡死）。
  兩個 P0 都在「玩家正常遊玩 10 分鐘內必踩」的路徑上，因此目前**勉強能玩，但一局打不完**。
- 數據面：城池一覽/內政 HUD/勢力圖列表/名冊數值/君主卡與 `game/data` 存檔/劇本數據總體一致；錯值集中在「新局未重置舊局狀態」（勢力圖滅亡 11、存檔讀回陣亡局）與「出征兵數口徑」（上陣 110 vs 10、deployQueue 9/10/10/100）。

### 5.2 最該先修的 5 條（按優先級）
1. **P0 全局輸入兜底 + 換月/出征穿透**：`Input._emitEvent` 外層 try/catch；出征編成確認後吞掉同幀 touch；`advanceMonth` 整段 try/catch 並恢復 UI。→ 一次性消滅「點一下整個遊戲就不動了」的兩類事故。
2. **P0-1 的根因防禦**：`CityPanel.mergeSave` 所有 `.slice()` 判空（`bag` 等），並在 `civic` 換月前校驗存檔結構（缺 key 時補默認值）。
3. **P0-2 戰鬥技能格崩潰**：`loadMagicProgram/newSkillRun` 對 shader/program 名判空 + 施法 try/catch + 失敗降級（無特效照算傷害）。
4. **P1 出征兵數口徑統一**：`上陣 N 兵` 文案、滑杆上限、快捷鈕「超上限」、deployQueue/armies 兵數全部從同一個「可帶兵數 = min(城內兵, 帶兵上限)」推導，禁止出現 10 兵打 110 兵與 100 兵無源。
5. **P1 新局重置 + 存檔一致性**：newGame 重寫全部相關 key（campaign/cities/forces/battlelog/run/slots 快照）；存/讀使用同一 snapshot；勢力圖「存續+滅亡=19、第 1 年 0 滅亡」。

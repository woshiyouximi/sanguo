# 04b1 · 阵形站位表（Formation Slot Tables）

> 《三国群英传2》(Sango2.exe, 1999) 的**布阵坐标数据 + 生成算法**完整逆向。
> 所有结论均给出 VA（虚拟地址）与文件偏移；推测项在正文中逐条标注「推断」。
> 上一份文档：`04b_战斗系统.md`（战斗系统总览）。本文件只讲**阵地站位**。

## 0. 一句话结论

> 9 种阵形不是"公式生成"的，而是 **9 组硬编码坐标数组**：
> 每个阵形有 **1 个锚点 X + 5 个分区（mode1..mode5）**，每区一个 `{int16 x, int16 y}` 数组
> 和一个权重 `w`（5 个权重**恒等于 200**）。
> 带 N 个兵时，第 m 区放 `w_m × N / 200` 个人，第 r 个人取该区数组的**第 r 项**，
> 最终落在 **71 列 × 14 行**的战场网格上：

```text
格X = 表X + 锚点X + (200 − N) / 25          ← 0x404DAF 加锚点，0x442CB6 加人数偏移
格Y = 表Y                                    ← 直接取表里的 y（Y 锚点恒为 0）
A 侧（0x4A8A60）再镜像：格X = 71 − 格X        ← 0x442D1B
```

- 5 个分区不是"阵形变体"，而是**同一个阵形的 5 个部位**（前段/中段/两翼/本阵…），
  按权重把兵**按比例塞进各部位**；兵越少，各部位只用数组开头（最靠内）的若干格。
- 阵形号 0..8 = 九种阵形；9 = 亂陣；10 = 特殊陣型；**11..19 / 22..32 是两个"变形族"**
  （`unit+0x10` 置位时把阵形号加 11 或加 22，见 §6）。
- 坐标数组容量**恰好等于该区权重 w**（满员 200 人时的 slot 数），已用相邻指针差逐一核对。

## 1. 战场网格（先定坐标空间）

| 项 | 值 | 证据 |
|---|---|---|
| 网格宽（列） | **71**（x = 0..70） | `0x43AF54`：`cmp [ebp+8], 0x47; jge → 无效` |
| 网格高（行） | **14**（y = 0..13） | `0x43AF54`：`cmp [ebp+0xc], 0xE; jge → 无效` |
| 每格像素 | **96 × 72** | `0x43A4E0`：`px = x*0x60 + 0x30`、`py = y*0x48 + 0x24` |
| 战场像素范围 | 6816 × 1008 | 71×96 / 14×72（横向卷屏） |
| 占位数组 | `0x4B3CA0`，每格 1 个 dword 对象指针，**行 stride `0x11C`（=71×4）** | `0x43AF7A`：`[y*0x11C + x*4 + 0x4B3CA0]` |
| 权重数组 | `0x4B4C54`，每格 16.16 定点，同行 stride | `0x43B028` 的 7×7 核叠加（见 04b §5） |
| 7×7 权重核 | `0x48E528`，`7 − max(|dx|,|dy|)` | 04b §3.4 |

**格→像素换算函数**（三个入口）：

```text
0x43A4E0(x, y, &px, &py):  px = x*0x60 + 0x30 ; py = y*0x48 + 0x24    // 0x43A4E6 / 0x43A4F4
0x43A501(x)          :     px = x*0x60 + 0x30                          // 只有 X
0x43A50F(y)          :     py = y*0x48 + 0x24                          // 只有 Y
```

> 所以阵形表里的坐标是**格坐标**，不是像素；渲染前必须过 `0x43A4E0`。

## 2. 三张数据表与取值函数

### 2.1 指针表 `0x485B10`（33 行 × 5 个 dword，stride `0x14`）

```asm
; 0x404DAF
00404DBA  imul  eax, [ebp+0x10], 0x14      ; a * 20
00404DBE  mov   eax, [eax + ecx*4 + 0x485B10]   ; ecx = mode-1
```

| 项 | 值 |
|---|---|
| 表基址 | `0x485B10`（文件偏移 `0x07F310`） |
| 行数 | 33（`a >= 0x21` 视为非法） |
| 行 stride | `0x14` = 5 个 dword |
| 列 | mode1..mode5 各一个 `u32` 指针，指向该区的坐标数组 |

行号 `a` 与阵形的对应：`0..8` = 九阵，`9` = 亂陣，`10` = 特殊陣型，
`11..19` = 九阵的变形族 A，`20/21` = 亂陣/特殊陣型的副本，
`22..32` = 九阵的变形族 B（`22..30` 对应 `0..8`，`31/32` 对应 9/10）。

### 2.2 权重/锚点表 `0x485DA8`（33 行 × 6 个 int16，stride `0x0C`）

```asm
; 0x40479F / 0x404A10 等
004047A6  imul  eax, [ebp+8], 0xC
004047A9  movsx ecx, word ptr [eax + 0x485DAA]   ; +2 = w2
```

| 行内偏移 | 含义 |
|---|---|
| `+0x00` | w1（mode1 权重） |
| `+0x02` | w2 |
| `+0x04` | w3 |
| `+0x06` | w4 |
| `+0x08` | w5 |
| `+0x0A` | **锚点 X（anchorX）**，唯一读取者 `0x404780` |

**关键恒等式：`w1+w2+w3+w4+w5 ≡ 200`**（33 行全部成立，已逐行核验）。
200 = 满员兵力上限，所以权重就是"满员时该部位占几个位置"。

### 2.3 坐标数组（entry = `{int16 x, int16 y}`，4 字节）

容量 = 该区权重 `w`，已用相邻指针差核对（例：雁形之阵 mode1 `0x482388` → mode2 `0x482428`，
差 `0xA0` = 160 B = **40** 项，正好等于 w1 = 40）。

### 2.4 三个取值函数

```c
// 0x404780  (31 B)  —— 阵形锚点 X
int GetAnchorX(int a) {
    if (a >= 0x21) return 0xB;                       // 0x404782 jae
    return (int16)*(int16*)(0x485DB2 + a*0x0C);      // 0x485DA8 + 0x0A
}

// 0x404DAF  (209 B)  —— 取第 slot 个兵的格坐标（唯一调用者是 0x442D38）
void GetSlotPos(int a, int slot, int mode, int16* out, int anchorX) {
    if (a >= 0x21) return;                                        // 0x404DB2
    int* base = *(int**)(0x485B10 + a*0x14 + (mode-1)*4);         // 0x404DBE
    if (base == 0) { out[0] = out[1] = 0; 0x42FDA5(10); return; } // mode 无数组 → 报错
    out[0] = (int16)base[slot*2]     + anchorX;                   // 表 X + 锚点X
    out[1] = (uint16)base[slot*2 + 1];                            // 表 Y（不加任何锚点）
}

// 0x404A10 (151 B) 族，步兵分组人数；0x404D18 (151 B) 族，骑兵分组人数
//   两个函数都是 5 路 switch，跳表 0x404A93 / 0x404D9B
int GroupCount(int a, int N, int mode) {
    if (a >= 0x21) return 0;
    int w = (int16)*(int16*)(0x485DA8 + a*0x0C + 2*(mode-1));
    if (w == 0) return 0;
    return w * N / 0xC8;                              // 0xC8 = 200，0x404AD9 idiv
}
```

> `mode1` 的步兵分组是**余数**：`0x40499D` 返回 `N − (m2+m3+m4+m5)`；
> 骑兵族 `0x404D18` 用**前缀和差**（`0x404CA5` 先减 `0x404AA7` 再减后面几项）。
> 两种写法结果都 ≈ `w_m × N / 200`，差别只在舍入的那 1 个人落在哪一区。

## 3. 布阵算法（完整伪代码）

### 3.1 顶层：`0x442EFA`（B 侧 = `0x4B03A0`，1438 B）/ `0x443498`（A 侧 = `0x4A8A60`，1441 B）

两侧代码对称，只有阵形号来源与镜像方向不同。

```c
void BuildSide(int side) {                       // side=0 → 0x4B03A0(B)；side=1 → 0x4A8A60(A)
    int formation = side ? [0x4A6674] : [0x4A6678];    // 0x442F00 / 0x4A6678=B 侧
    [0x48E4C8] = GetAnchorX(formation);                // 0x442F14  锚点 X
    // [0x48E4D0] 是锚点 Y，全 EXE 只读不写 → 恒 0，所以 y 不加锚点
    ...
    [0x4A8A40] = formation;        // 0x4431D2  当前阵形号（0x404DAF 的 a）
    [0x4B0380] = 0;                // 0x4431C5  全局 slot 游标
    [0x4A8A44] = 0;                // 0x4431A3  Angle（恒 0，见 §8）
    [0x4B7B18] = thing;            // 0x4431B6
    [0x4AC360] = 0;                // 0x4431BB

    int N_步 = 0x406499(1, thing); // 步兵数
    int N_骑 = 0x406501(1, thing); // 骑兵数
    int N   = N_步 + N_骑;

    // 主将位置：行固定 6，列由 0x442CB6 算
    0x442CB6(&gx, &gy, [0x48E4C8], [0x48E4D0], N, 0, unit->+0x68);
    // 0x44315D 用 gx 作列、行 6（0x6A8 = 6*0x11C）查 0x4B3CA0；空则 unit->+0x40 = unit

    int startSlot = 0;
    for (mode in {1, 3, 4, 5, 2}) {                    // 0x4431D8/0x443264/0x4432F0/0x44337C/0x443408
        int kc = GroupCountCav(formation, N_骑, mode); // 0x404D18
        SpawnUnits(unit, mode, /*start*/0, kc, N_骑, /*isCav*/1, N);
        startSlot = kc;
        int ki = GroupCountInf(formation, N_步, mode); // 0x404A10
        SpawnUnits(unit, mode, startSlot, ki, N_步, /*isCav*/0, N);
    }
}
```

> **分区内的先后次序：骑兵占该区数组的低位 slot（0..kc-1），步兵接着占 kc..**
> 也就是"内圈/前排给骑兵"。`0x443180`–`0x4432E8` 的两段 push 顺序逐条核对得出。

### 3.2 生成循环：`0x442D38`（450 B）

```c
void SpawnUnits(int unit, int mode, int startSlot, int count,
                int troopCount, int isCav, int N) {
    for (int i = 0; i < count; i++) {
        int16 x, y;
        GetSlotPos([0x4A8A40], startSlot, mode, &x, &y, [0x48E4C8]);   // 0x404DAF

        int X = x + (200 - N) / 25;                 // 0x442CC2..0x442CD5  idiv 0x19
        int Y = y;

        // 站位 X 的 4 路变体（0x442CDA..0x442D18），由 unit+0x68 选择
        switch (unit->+0x68) {
            case 1: case 2: X = x + 0xC; break;     // 不去掉人数偏移，另加 12
            case 3: X = x;               break;     // 去掉 (200−N)/25
            case 4: X = 0x22 - X;        break;     // 34 − X 反向
        }

        if (unit == 0x4A8A60) X = 0x47 - X;         // 0x442D1B..0x442D29  A 侧镜像（71 列）

        // 占位探测：目标格已被占 → 沿行方向往外挪一格，直到找到空格（0x442DAF..0x442DDF）
        while (GetCellObject(X, Y) != 0) {                               // 0x43AF7A
            if (X <= 1)   X += 0x20;
            if (X >= 0x70) X -= 0x20;
            if (X >= 0x36) X += 1; else X -= 1;      // 有效范围内：远离列 54
        }

        int idx  = [0x4B0380]++;                     // 0x442DE1  全局 slot 游标
        Slot* s  = (Slot*)(unit + 0xB4 + idx*0x48);  // 0x442DF6  槽基址 unit+0xB4，stride 0x48
        s->+0x40 = unit;                             // 0x442DE9  回指（等价 unit+0xF4+idx*0x48）
        0x442A1A(X, Y, troopCount, [0x4A8A44] /*=0*/, s);
        0x43AEE5(s);
        0x43B51E(s, isCav ? 4 : 2);
        startSlot++;
    }
}
```

### 3.3 单兵落地：`0x442A1A`（238 B）

```c
void SpawnOne(int x, int y, int troopCount, int angle, Slot* s) {
    if (!0x43B467(x, y)) {                                  // 越界
        printf(0x4903D8 /* "無法產生士兵，x=%d  y=%d  Angle=%d" */, x, y, angle);
        return;                                             // ← 这就是那句调试串的出处
    }
    s->+0x08 = x;  s->+0x0C = y;                            // 逻辑格坐标
    s->+0x10 = x;  s->+0x14 = y;                            // 另一份（渲染用插值缓存）
    s->+0x2C = 0;
    0x43B028(x, y, s);                                      // 占格 + 7×7 权重叠加
    0x43A4E0(x, y, &px, &py);                               // 格 → 像素
    int obj = 0x4217FE(px, py, 0, …);                       // 建图形对象
    s->+0x44 = obj;  obj->+0x84 = s;                        // 双向回指
}
```

> **这句 `0x4903D8` 调试串一直没有 imm32 引用**（04b §8 的未解项）——原因是它被
> `0x442A1A` 用 **`0x4903D8`** 而不是 `0x4903D9` 引用（串内容以 `無法` 开头，
> 前一处 `0x4903D9` 是我的误读）。本文件已把它接上。

## 4. 人数 → 分区（10 / 50 / 100 人怎么扩）

```text
每个分区的人数（步兵族）：k_m = w_m × N_步 / 200，其中 mode1 吃余数
每个分区的人数（骑兵族）：k_m = w_m × N_骑 / 200，前缀和差（≈ 同上）
一个分区占用的 slot 数 = k_骑(m) + k_步(m)
士兵站位 = 该区数组第 (0 .. k_骑+k_步-1) 项
```

因为 `Σw = 200`，所以 **200 个兵时每个区的数组恰好被填满**；兵少时只用到数组开头。

| 阵形 | w1..w5 | N=10（纯步兵） | N=50 | N=100 |
|---|---|---|---|---|
| 0 方形之陣 | 140/60/0/0/0 | m1:7 m2:3 | m1:35 m2:15 | m1:70 m2:30 |
| 1 圓形之陣 | 60/140/0/0/0 | m1:3 m2:7 | m1:15 m2:35 | m1:30 m2:70 |
| 2 錐形之陣 | 150/50/0/0/0 | m1:8 m2:2 | m1:38 m2:12 | m1:75 m2:25 |
| 3 雁形之陣 | 140/60/0/0/0 | m1:7 m2:3 | m1:35 m2:15 | m1:70 m2:30 |
| 4 玄襄之陣 | 40/42/40/40/38 | m1:3 m2:2 m3:2 m4:2 m5:1 | m1:11 m2:10 m3:10 m4:10 m5:9 | m1:20 m2:21 m3:20 m4:20 m5:19 |
| 5 魚麗之陣 | 60/90/0/0/50 | m1:4 m2:4 m5:2 | m1:16 m2:22 m5:12 | m1:30 m2:45 m5:25 |
| 6 鉤形之陣 | 140/60/0/0/0 | m1:7 m2:3 | m1:35 m2:15 | m1:70 m2:30 |
| 7 衝鋒之陣 | 54/70/38/38/0 | m1:5 m2:3 m3:1 m4:1 | m1:15 m2:17 m3:9 m4:9 | m1:27 m2:35 m3:19 m4:19 |
| 8 箭矢之陣 | 108/92/0/0/0 | m1:6 m2:4 | m1:27 m2:23 | m1:54 m2:46 |

> 注意：`(200 − N)/25` 这个整体平移项在兵少时**把阵形往中线推**（N=10 → +7 列，
> N=200 → +0 列），所以 10 个兵不是"缩成一点"，而是"整体前移、只用内圈格"。

## 5. 九种阵形的完整站位表

> 每节给出：分区权重 + 数组地址（VA / 文件偏移）+ 覆盖格范围 + **全部 slot 坐标**。
> 表中坐标是**表内坐标**，实际格 = `x + 锚点X + (200−N)/25`、`y`（A 侧再 `71 − x`）。

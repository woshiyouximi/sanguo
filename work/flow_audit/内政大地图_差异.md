## 1. 年份与月份推进

### 原作依据
- 指南 L21-23「每年 1 月停下来管一次家（内政），剩下整整一年在外面跑兵打仗」
- 指南 L27 / L31 流程图「每年1⽉ ──▶【内政模式】」「【大地图模式】跑⼀整年」
- 指南 L39-41「每年只有 1 月份能坐在家里数钱、招兵、修城墙；其他 11 个月，你的军队都在外面走」
- 指南 L43-45 三条铁律，其一「每个武将每年只能做一件事（搜索 或 开发，二选一）。」
- 指南 L106-107「注意：每个武将每年只能执行一次搜索或开发；出征在路上的武将、年末没回城的武将，这一年不能内政。」

## 3. 金钱 → 预备兵（最严重的规则缺失）

### 原作依据
- 指南 L122-124（"💰最重要的自动规则：钱变兵"）：「城里每 100 金钱 = 1 个预备兵，**随时间自动转换**，直到钱花光或兵满为止。所以别攒钱，城要丢了钱就全没了。」

### 现状（我们做了什么）
| 位置 | 事实 |
|---|---|
| `campaign.html:5177-5181` | 我们自己的注释：「唯一消耗口是 `0x41AF58` 的补兵（**100 金 → 1 預備兵**）」——**规则写在注释里，代码里没有** |
| `city_model.js:687-704` | `refillPrep()`：**每月白补预备兵上限的 10%**，`prepGainPct: 0.10`，`INCR` 里标 `'新設計'` |
| `city_model.js:710` | `enlist()` 注释臆测出一条不存在的链：「不花金……金的去处是开发（**金→人口→预备兵→兵**）」 |
| `campaign.html:5205-5221` | 换月时**守军每月白补上限的 2%**（`Math.ceil(cap * 0.02)`），注释自称"与 Saves.cityTroops 同一口径" |
| `city_model.js:69-105` | `INCR` 表里根本没有 `prepPerGold` 这一项；`prepDiv:2500`／`prepBase:110` 只是**上限**公式 |

### 实测（`steps_flow_months.mjs`，连推 12 月）
```
T0  金1200 预备兵200 兵200 防205
T1..T11 金1200 预备兵200 兵200 防205  ← 11 个月，钱一分没少，预备兵一个没多
T12 金5141 预备兵200 兵200 防205      ← 只多了正月岁入 3941
```
⇒ **"钱变兵"在实机里完全不存在**。

### 差异 / 修法
| ID | 差异 | 严重度 | 修法 |
|---|---|---|---|
| F13 | 「100 金 = 1 预备兵，随时间自动转换」**未实现**，被"每月白补 10%"顶替 | **P0** | 换月时每城：`n = min(floor(money/100), prepCap-prep, 兵上限未满量)`；`money -= n*100`；`prep += n`。删掉 `refillPrep` 的白补，或标 `?loose=1` 保留对照 |
| F14 | 守军每月白补 2%（`campaign.html:5214`）——原作没有"守军自然回补"，兵要么在将名下、要么是预备兵 | **P0** | 删除该段；守军数 = Σ 将兵（或直接由预备兵徵兵而来） |
| F15 | **大地图「徵兵」是第三套口径**：`campaign.html:3717-3720` `save.gold -= 500; st.troops = Math.min(600, st.troops+40)`，不吃预备兵、不看武将 | **P0** | 删掉大地图徵兵键，或改成打开城内徵兵抽屉（`city.html:760-824` + `city_model.js:714-735 enlist`） |
| F16 | **钱的口径分裂**：`save.gold` 单钱包 vs 原作每城 `money(+0x92)`。实测同屏两个数：顶栏「金 1,200」、列表行「$3,941」 | P1 | 统一到每城 `money`，国库 = Σ；`city.html` 的「金」chip 标明是哪个 |
